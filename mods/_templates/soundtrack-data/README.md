# Плейлист без кода

Шаблоны внутри `_templates` игра не загружает. Скопируйте эту папку в свой мод
в `Документы/Bayte Realization/Deal or Force/mods`, задайте собственный `id` и имя
в `manifest.json`, включите пакет через лаунчер. Для ручного запуска пакета без
выбранного набора проверьте также `enabled` манифеста. Сам манифест остаётся JSON.

`music/90_example.yml` добавляет запись в тот же музыкальный каталог, которым
пользуется адаптивный директор. Демонстрация ссылается на поставляемый игрой
`quiet_current.ogg` и не копирует его. Для своей музыки положите разрешённый вам
файл в `music/audio/` и задайте относительный путь `audio/my_recording.ogg`.
Наличие поддержки формата не даёт права распространять чужую музыку.

Поля: `label` — ключ названия RU/EN; `when` — menu/campaign/any; `moods` — условия
автоподбора; `weight` — относительная частота; `volume_db` — поправка громкости;
`loop` — повтор записи. Свой ID добавляет трек, совпавший с базой — переопределяет
его. Ключи сохраняются в именах пакета, не переводите их вместе с подписями.

В игре откройте кнопку ноты или «Звук / Арт». Верхний список плеера содержит
**все объявленные треки**, даже без отдельной записи в `presentation/assets`.
Ручной выбор обходит фильтры настроения/региона, но не общий уровень громкости.
Он продолжает играть после закрытия окна и смены сцены. Кнопка автоподбора
возвращает управление директору. Следующий/предыдущий идут по ID каталога;
список выбора сортируется по переведённому названию.

Нижние кнопки прослушивания — другой режим: звук/видео из галереи останавливаются
при её закрытии. Только declared music становится саундтреком; эффекты тревог
и случайные локальные файлы не попадают в плейлист автоматически.

Пауза музыки не ставит на паузу кампанию. Выбор плеера не хранится в её сейве,
не тратит RNG симуляции и не меняет численные правила. Он действует в пределах
текущего запуска игры; перезапуск приложения начинает с автоматического режима.

Проверка без движка: `Tools/dev.ps1 -Test -TestArgs '--music-transport-only'`.
Проверка воспроизведения/переходов и RU/EN геометрии — через игровой probe,
не через одно только существование YAML-файла.
