# Sounds template / Шаблон звуков

Overrides sound channel gains, UI/strategic cues (`cues`), and tactical camera ambience
beds (`map_ambience`) layered over `game/sound/`.

To supply custom `.ogg` or `.wav` recordings, drop them into `sound/audio/` beside this
file and set `"file": "audio/my_sound.ogg"` (relative to `sound/`).
