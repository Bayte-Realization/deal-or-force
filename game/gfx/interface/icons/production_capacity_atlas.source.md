# Production capacity atlas — provenance

`production_capacity_atlas.png` contains two original factory pictograms generated
for Deal or Force via CreativeClaw (Nano Banana 2), followed by CreativeClaw
background removal. No HOI4 artwork was extracted or included.

- Generation job: `83bb15a2-3d7b-456e-a4df-8e9a75c5d6ba`
- Background-removal job: `7a46dd68-ab65-4c56-8bda-c9898f73e4b9`
- Transparent asset: `d5d61808-39e2-4943-b816-15259309b742`
- Left half: civilian factory. Right half: military factory with shell.

The UI trims transparent margins and applies the existing semantic palette at
runtime. Mods may override `production_civilian` and `production_military`
independently; see `game/documentation/production_units.md`.
