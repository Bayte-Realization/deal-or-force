# Подписи и значки верхней панели

Показатели используют общую палитру интерфейса: золотой значок, приглушённая
подпись, светлое значение и отдельная строка изменения. Баланс — изменение казны,
а не валовой доход. Движения без территории показывают собственные показатели;
при возвращении к стране восстанавливаются её значки, подписи и подсказки.

`gui/29_hud_readability.json`: `hud.stat_labels = 1` включает подписи.
Мод может установить `0` для компактного вида. Если значка нет, подпись остаётся.
Переводы подписей находятся в `localization/`, порядок — в
`campaign.top_stats` файла `gui/20_campaign_structure.json`.

Значки заменяются через `gfx/interface/icons/icon_<роль>.png` или SpriteCatalog:
`treasury`, `balance`, `gdp`, `inflation`, `population`, `stability`, `manpower`.
Не используйте одну и ту же пиктограмму для баланса, ВВП и стабильности.

## Назначения значков и режимы карты

`gui/30_icon_roles.json` хранит `campaign.icons`: назначения `hud.TREASURY`,
`hud.BALANCE`, `hud.GDP`, `hud.INFLATION`, `hud.POPULATION`, `hud.STABILITY`,
`hud.MANPOWER` и `map.Political/Diplomatic/Wars/Population/Economy/Terrain/Relief`.
Значение — имя значка без префикса `icon_`, например `gdp`. Поздний файл мода
может переопределить одну пару, остальные наследуются. Это меняет назначение,
не заменяя рисунок во всех других местах. Применяется при построении интерфейса.

`map_controls.active_label = 1` показывает название выбранного режима рядом с
иконкой; `0` возвращает компактную панель. Все семь режимов доступны одним кликом.
Экономическая карта показывает **ВВП стран**, а карта населения — **численность
стран**, не плотность жителей и не выпуск отдельных регионов. Подсказки следуют
реальной раскраске, включая ограничения разведданных.

Окно событий строит столько кнопок ответа, сколько задано в `options` события.
Большой список прокручивается, вместо обрезания после двух вариантов.
