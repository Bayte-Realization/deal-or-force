# Флаги и маркеры движений: настройки для модов

Файлы мода размещаются в его папках `common`, `gfx` и `gui`, повторяющих
структуру `game`. Не меняйте базовые изображения, если достаточно заменить
привязку спрайта в JSON.

## Замена изображения флага

В `gfx/flags/my_flags.json`:

```json
{
  "sprites": {
    "flag_sau_traditionalism": {
      "texture": "res://game/gfx/flags/flag_sau.png"
    }
  }
}
```

Это пример привязки к существующей игровой текстуре. Для собственного рисунка
укажите путь к своему ресурсу. Варианты с более конкретным идентификатором
имеют приоритет перед базовым `flag_TAG`; всегда проверяйте не только выбранный
идентификатор, но и его текстуру. Предпросмотр идеологии использует тот же
каталог, что и принятый режим.

## Удаление унаследованных правил

В `common/flags/my_rules.json`:

```json
{
  "also_answers_to": { "ideology": { "socialism": [] } },
  "own_flag_is_for": { "chn": {} }
}
```

Первое правило запрещает социализму брать варианты через унаследованные
псевдонимы. Второе снимает условия допустимости собственного китайского флага.
Это не отменяет приоритет явно существующих вариантов идеологии/правления.

Запись страны в `own_flag_is_for` заменяет её набор условий целиком.
`otherwise` также следует указать заново, если он нужен: отсутствие поля
удаляет прежний запасной флаг. Отсутствие самой записи страны ничего не меняет.

## Размер изображения внутри круглого маркера

В `gui/my_markers.json`:

```json
{ "metrics": { "movement_marker.art_radius": 46 } }
```

Число ограничивается диапазоном 16–48 и измеряется на исходном холсте 128×128.
Флаг вписывается по диагонали: его углы не касаются кольца, пропорции сохраняются.
Это размер рисунка **внутри** маркера, не размер всего маркера на экране.
После изменения перезапустите игру: созданные текстуры кэшируются.

## ЧВК и территориальные амбиции

В базовой игре ЧВК нет: её мир — настоящий мир 2024 года. Готовый пример вымышленной
компании (Vector Security Group) лежит в `mods/_templates/private_military_company`.

В `common/movements` обычный признак `for_hire` означает наёмную компанию,
которая работает по контрактам, но не захватывает чужие регионы восстаниями.
Для специально задуманного военизированного территориального движения мод
может явно задать оба признака:

```json
"traits": ["for_hire", "territorial_ambition"]
```

Остальные ограничения и расходы восстания продолжают действовать. У такого
подрядчика восстанавливается прежний денежный расчёт шанса, без требования
местной поддержки — используйте признак осознанно. Для обычных национальных
движений и правительств в изгнании этот дополнительный признак не требуется.
Изменение правил не перераспределяет территорию существующих сохранений.
