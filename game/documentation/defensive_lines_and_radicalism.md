# Оборонительные рубежи и динамика радикализма

## Оборона

Выделите свои дивизии, нажмите **Оборона**, протяните правую кнопку мыши по
контролируемой суше и отпустите. Приказ действует сразу, в мирное и военное
время: дивизии маршируют к назначенным позициям, удерживают их и окапываются.
Это отдельный рубеж внутри территории, а не наступательная цель или фронт
по государственной границе.

Линия привязана к последовательности соседних провинций. Пропущенные мышью
небольшие промежутки достраиваются по доступной суше. Возвращение по линии
укорачивает её; чужая территория, вода и длинные скачки не добавляются.
Отображаемая лента проходит через центры провинций, не по их точным границам.

Если дивизий достаточно, количество на позициях отличается не более чем на
одну. Если их меньше, позиции выбираются через равные интервалы вдоль списка
провинций. Свои корректные назначения сохраняются, чтобы не гонять войска
между участками ежедневно. Утраченные позиции исключаются, без приказа
автоматически штурмовать их обратно.

Для изменения выберите дивизии одного рубежа, нажмите **Оборона** и начертите
новый рубеж с **Alt + ПКМ**. **Esc** отменяет рисование. Недопустимая команда
не заменяет прежний план. Назначение требует, чтобы выбранные дивизии не были
в бою или на транспорте и могли добраться до рубежа по своей суше.

Порядок провинций сохраняется в `DrawnFrontLine.DefensiveSequence`; старые
сохранения с неупорядоченным набором позиций читаются совместимо. Максимум
256 позиций и предел достраивания в 16 шагов заданы в `DefensivePlanning.cs`.

## Радикализм

Недельное изменение объединяет условия жизни, бюджет, правительство,
идеологию, меньшинства, оккупацию и инфляцию. От суммы вычитается постепенное
успокоение, пропорциональное текущему радикализму. Условия жизни ускоряют
восстановление, война замедляет. Инфляция учитывается один раз.

Настройки: `game/common/defines/35_radicalism.json`:

- `RegionalRadicalismRecoveryPerWeek`: базовая доля восстановления в неделю;
- `RegionalRadicalismLivingRecovery`: добавка к скорости от уровня жизни;
- `RegionalRadicalismWarRecovery`: множитель восстановления во время войны;
- `RegionalRadicalismOccupation`: недельное давление полной оккупации региона;
- `AiRadicalismConcern`: средневзвешенный по населению порог реакции ИИ.

Это доли 0–1, не проценты. При уровне жизни 0,5 базовое восстановление
составляет 0,007 от текущего радикализма в неделю. Другие давления продолжают
действовать: высокая напряжённость возможна, но 100% не является необратимым
состоянием. Старые сохранения не обнуляются и не требуют миграции.

Платёжеспособный ИИ повышает социальные расходы при высоком радикализме даже
при высокой общей стабильности. Страновых исключений, включая Россию, нет.
В подсказке радикализма региона видны составляющие недельного прогноза и
способы повлиять на него. Прогноз не включает разовые события и скриптовые
национальные модификаторы.

## Проверки

Из корня проекта:

```powershell
dotnet run --project Tools/ArmyInteractionTests -- --defence-only
dotnet run --project Tools/ArmyInteractionTests -- --radicalism-only
dotnet run --project Tools/ArmyInteractionTests -- --offensive-only
dotnet run --project Tools/SimBench -- 3650 20260830 --radicalism
```

В сравнении двух десятилетних прогонов текущего сценария с одинаковым seed
средний региональный радикализм: до изменений 16,9%, после 5,9%; регионов
на 100%: 2/1848 и 0/1850 соответственно. Число регионов может меняться по
ходу кампании. Это одна регрессия, не гарантия баланса всех сценариев. Массовые
100% из пользовательской партии на свежем сценарии не воспроизведены;
восстановление из насыщенного сохранения проверено отдельным тестом.
