# Contemporary interface surfaces

These original textures form the default `Deal or Force` interface material set.

- `panel_dossier.png` — primary 9-slice panel surface: graphite/navy document cloth, quiet centre, restrained brass registration edge.
- `panel_command_frame.png` — secondary 9-slice command surface with clipped corners, steel-blue rules and sparse brass registration marks. Used for map controls, the strategic outliner, alerts, navigation and the army roster so functional controls read differently from dossiers.
- `panel_inset.png` — borderless cartographic inset for tables, tooltips and dense information areas.
- `icon_concepts.png` — an exploratory pictogram sheet. It is intentionally not wired into production UI until the symbols are reduced to the flatter house style.
- `Icons/*.svg` — the production navigation pictograms. They are deliberately flat, monochrome and vector-based so they stay crisp at every UI scale and are straightforward for a mod to replace.

Keep interface surfaces low-contrast behind text. Gold is reserved for focus, selection and actionable emphasis; red is reserved for force, danger and destructive actions. New surfaces should remain contemporary and tactile without neon, circuitry or overtly futuristic ornament.

The generated originals were created from these art directions:

- Primary panel: modern government briefing dossier, dark graphite/midnight navy, fine woven grain, micro-grid and faint cartographic traces, quiet centre, restrained brass edge.
- Command panel: modern operations-room frame, dark graphite navy woven technical fabric, clipped corners, thin steel-blue rule, tiny muted brass corner marks, minimal depth, transparent outer corners and a quiet 9-slice centre.
- Inset: desaturated blue-gray coated paper, subtle contour lines and registration marks, uniform low contrast.
- Icon study: six geopolitical categories using brass and pale blue-gray geometric pictograms on transparency.

Brand assets live beside this folder in `../Brand`. `deal_or_force_logo.png` is the untouched, tightly-cropped user artwork; `deal_or_force_logo_menu.png` is a non-destructive display derivative with only the navy strokes lifted for contrast on the dark menu panel.
`deal_or_force_logo_banner.png` is a non-destructive wide menu derivative of the user's opaque paper-backed artwork. The mark keeps its original proportions while the sampled paper field reaches both sides of the menu.
