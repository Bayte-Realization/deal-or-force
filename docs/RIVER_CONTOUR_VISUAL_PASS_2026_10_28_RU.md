# Контуры рек и защитное поведение графики — 28 октября 2026

## Что изменено

Сохранена существующая растровая география. Диагональные соседние клетки реки
теперь получают короткий скруглённый стык в **отдельном визуальном SDF**. Настоящие
пробелы между несоседними клетками не достраиваются. Исходный HydrologyRaster,
озёра, переправы и сила речных преград не изменяются.

Шейдер карты сглаживает ступенчатые берега положительным кубическим B-spline
фильтром: четыре дополнительные аппаратно-линейные выборки только возле реки.
Ограничение сдвига сохраняет короткие истоки. Новых речных mesh, узлов и больших
текстур нет. `map.river_curve_filter` в `game/interface/04_river_contours.json`
задаёт интенсивность фильтра 0–1. Это улучшение контура существующего растра,
**не новая точная векторная география** и не обещание повышения FPS.

Найдена покадровая повторная загрузка `icon_battle`, если импорт отсутствует.
Успех и неудача теперь кэшируются по пути; изменение пути или перезагрузка
SpriteCatalog разрешает новую попытку. Загрузка выполняется только для реально
рисуемого значка. При отсутствии ресурса остаётся простой знак скрещённых линий.
Подписка на каталог снимается при выходе узла из дерева.

Русский заголовок группы навигации «МИРОВЫЕ СОБЫТИЯ» больше не рисуется за
пределами узкой колонки: переносится по словам, контейнер учитывает высоту.
Названия вкладок и правила симуляции не менялись; новых строк локализации нет.

## Изоляция и ограничения

Стенд `build/.river-atlas-20261028/project` имеет собственные исходники сборки,
DLL, `.godot` и тестовый каталог пользовательских данных; миграция настоящих
сохранений в его приватной копии GamePaths отключена. Ресурсы читаются из
проектного `game` через junction. Плагины основного редактора не отключались,
его кэш/DLL не перезаписывались. Настройки стенда сохранены через Godot ConfigFile.
Рабочие игровые/редакторские процессы пользователя не останавливались.

Первые снимки имели неполный импортный кэш и не считаются чистой приёмкой всего
интерфейса. В последнем прогоне остались **2 UID warning** из копии сцен,
**4 сообщения** об одной отсутствующей импортированной загрузочной картинке
`loading_lantern_square.jpg` и **3 rendering ERROR** `Too few vertices (2)`
при новом просмотре шва 180°. Причина последнего пока не установлена: глобальная
чистота рендера **не закрыта**, нулевое число ошибок не заявляется.

Проверен Forward+/D3D12 на RTX 3060, не весь набор рендереров/устройств. Полный
стенд, SimBench, длительная партия, экспорт EXE/PCK и GitHub не выполнялись.
Не менялись версия, сохранения, баланс, сеть и языковые backend. Rust/BTA не тронуты.
