# Фактура приборов, мастерская и реальный языковой эксперимент

Это проверяемый срез, не завершение всей [очереди](TODAY_QUEUE_2026_11_06_RU.md).
Новый публичный ZIP этим отчётом не объявляется. Itch.io не публиковался.

## Оформление

Общие кнопки, навигационные кнопки HUD и кнопки редакторов получили общие
сгенерированные nine-slice текстуры. Есть верхняя освещённая кромка, нижняя тень,
тонкая фактура и обратный рельеф нажатого состояния. Полосы в списке дивизий,
исследованиях, финансах и диаграммах используют утопленную дорожку и поднятое
заполнение. У ползунков — ручка с насечками, отдельный disabled-вариант.

Цвета по-прежнему задаются ролями InterfaceSkin; степень рельефа и зерно —
`atlas.relief` и `atlas.grain` в обычном GUI/skin overlay. Чужие игровые текстуры
не копировались. Направление — матовая приборная панель, а не яркий блеск под
каждой строкой. В качестве визуального ориентира разобран официальный
[Graphic Overview Victoria 3](https://www.paradoxinteractive.com/games/victoria-3/news/dev-diary-49-graphic-overview):
акцент на действиях и их иерархии, спокойная основа под текстом.

Нет отдельного viewport, шейдера или process-цикла на каждую кнопку. Текстуры
64×32 кешируются и ограничены 128 вариантами; динамические цвета сверх лимита
получают обычную поверхность. Не менялись размеры области нажатия и отступы
между состояниями. Повторные 1000 запросов одной полосы используют тот же ресурс.
В проверенном проходе новый кеш показывал 14 текстур / 114688 RGBA-байт.
Это размер данного кеша, не измерение всей VRAM интерфейса и не замер FPS.

## Мастерская

У создания сценария, редакторов страны/флага/содержимого/раскладки и карты —
общий выход «К сценариям». Корневая библиотека отдельно возвращает в главное
меню. Вложенный редактор может иметь дополнительный возврат к предыдущему.
Новый несохранённый сценарий карты требует подтверждения даже до первого мазка;
выход не спрашивает дважды через RequestClose. Отмена оставляет редактор и правки.

Изменение имени новой копии теперь помечает её несохранённой. Закрытие уже
закрытой мастерской не запускает часы. Обновляемые изображения предпросмотра
флага освобождаются при замене/выходе; закрытые формы больше не удерживаются
полями мастерской.

Полное текущее DisplayName теперь является и MapName: государственное устройство,
провозглашённое/пользовательское имя и локализация одинаковы с дипломатией.
Укладка очень длинных полных названий на небольших территориях ещё требует работы.

## Языки: измерено, а не объявлено ускорением

Собран существующий Rust-прототип ядра связности владения; использован уже
установленный приватный toolchain, без новой установки. Семь Rust-тестов прошли.
На реальной карте seed 777: 34650 вершин, 90958 сухопутных рёбер, 51 повтор.
Топология и входы одинаковы, ABI-проверка/упаковка/выделение результата учитываются.

В одном native A/B-проходе, p50:

| Расчёт | Время |
| --- | --- |
| Прежний managed BFS с материализацией | 2.216 мс |
| Managed CSR с материализацией | 2.605 мс |
| Rust ABI с материализацией | 2.811 мс |
| Только managed CSR, включая упаковку воды | 0.687 мс |
| Проверенный Rust ABI, включая упаковку воды | 0.839 мс |

Для этого ядра Rust не выиграл; в production он не включён. Нельзя выдавать
скорость чистого алгоритма без выделения результата за скорость тика всей игры.
ECS-библиотека не подключалась; data-oriented прототипы других горячих стадий —
дальнейшая задача, а не выполненная интеграция.

Оба варианта прошли 30 дней, снимок на 15-м дне и точное продолжение после него.
Дополнительно сравнивались 31 ежедневная строка fingerprint/RNG/components.
Managed: 2468 проверок, Rust: 4642 проверки, оба OWNERSHIP_BENCH_PASS.

Первый прогон выявил реальную ошибку: MovementPeopleCache держал недельный
снимок населения, хотя люди успевали измениться внутри недели. Загруженная партия
читала свежие данные и расходилась с непрерывной. Кеш теперь ежедневный; смена
веры сбрасывает его сразу. Регрессии проверяют следующий день, холодный снимок,
изменение веры в тот же день и отсутствие расходования RNG при чтении.

## Проверки и ограничения

- Сборка ExportRelease: 0 ошибок, четыре прежних CA2255 на ModuleInitializer F# hooks.
- Общий FormableTests перед 2D-добавлением: 12908 PASS, exit 0.
- Native OpenGL и D3D12: по 167 PASS, EXPORT_VERIFY failures=0, exit 0,
  stderr пуст. EN/RU, 1920×1080 / 1280×720, реальное нажатие навигации,
  отмена/подтверждение выхода, снимки просмотрены. Это RTX 3060, не Intel HD 530.
- Диагностика основного живого проекта после среза оформления: 802 файла,
  0 diagnostics, runtime assembly редактора не перезагружена.
- Локализация: EN/RU без конфликтов, пустых строк и потери placeholders.
- Полный стандартный SimBench 365, seed 777: **24 красные проверки**.
  Есть рассогласование двух миров, проверки связности мира/мира после войн,
  военного ИИ, данные/устаревшие ожидания стенда. Ранее зафиксированный результат
  был 21; все дополнительные различия ещё не классифицированы.
  12908 зелёных unit-тестов не отменяют эти 24 результата и не означают стабильный релиз.

Исправлена оставшаяся ссылка SimBench на удалённый ConsoleVerse: стенд читает
обычную локализацию. Старый пустой локальный каталог common/console всё ещё
может попадать в файловый аудит; в Git он не содержит удалённых данных.

## Следующий узкий фикс: 2D

Найдено смешение движения дивизии и смены повторённого листа карты: при смене
знака X плавность интерполировала примерно 20 мировых единиц вместо локального
отрезка. Перед интерполяцией отображаемая позиция приводится к той же копии, что
целевая. Обычная плавность реального движения не отключена. Чистая регрессия
проходит оба направления, многократные обороты и 801 шаг горизонтальной прокрутки.
Финальные native-проверки этой добавки записываются отдельно ниже.

Добавка 2D проверена в настоящем OpenGL-процессе: обе стороны прохода через
стык вызывают production UpdateArmyMarkerMotion на отдельном визуальном счётчике,
который не добавляется в Campaign. Весь проход: **175 PASS**, failures=0, exit 0,
stderr пуст. Снимки до/после 180° и обратного перехода просмотрены. Чистая
проверка DateLineSeam — **19 PASS**, включая 801 шаг. Это не проверка всех
типов маркеров и всех масштабов 2D; крайние видимые копии листа ещё требуют аудита.

Реки, облака/маркеры и общий вид 2D, полное расширение религий и доктрин,
динамические войны бывших союзников, экономика и глобальные красные проверки
не объявляются закрытыми.
