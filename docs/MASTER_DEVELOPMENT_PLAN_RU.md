# Общий план Deal or Force — 16 октября 2026

Один контрольный список исходных пожеланий, последующих дополнений пользователя,
наших идей и плана Claude. Ничего ниже не становится готовым только от наличия
названия, файла, генерации или зелёной компиляции. План Claude прочитан целиком;
его отметки сохраняются как отчёт автора и сверяются с кодом и проверками.

Ветка разработки — **ReimAlpha**. Бинарные билды на GitHub не публикуются.
Чужие незаконченные изменения, редакторные плагины и мод BTA сохраняются.
Завершать крупные блоки в ближайшие дни — приоритет, не обещание закрыть всю
переработку за одну ночь. Пункты принимаются по результату, не по числу строк.

Статусы: **проверено** — есть названное свидетельство; **частично** — работающий
слой не закрывает весь запрос; **в работе** — текущая реализация ещё не принята;
**очередь** — не сделано; **внешняя ошибка** — результат не получен от сервиса.
Старые свидетельства не выдаются за повторный прогон сегодняшнего дерева.

   легитимность и гражданско-федеральный путь отделения; ранние предупреждения,
   ответы игрока и внешнее воздействие. Не случайный обязательный развал гегемона.

## Общая приёмка каждого механического блока

Данные и локализация → реализация существующего игрового цикла → цена/отказ/ответ
вUI → ограниченное сохраняемое состояние → split/merge и сетевой fingerprint →
позитивные/негативные тесты → выключатель/модовый overlay → наблюдение в кампании.
Баланс требует нескольких сидов и длинного горизонта. Изображение, музыка,
счётчик строк и компиляция отдельно не доказывают органичную симуляцию.
