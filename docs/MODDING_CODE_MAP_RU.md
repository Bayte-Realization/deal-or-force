# Как читать этот код (карта для моддеров)

**Дата:** 30 октября 2026. Это не описание всех систем — это порядок, в котором их читать, и
правила, по которым они написаны. Систем шесть десятков; без карты в них не войти.

## Три комментария в коде, с которых всё начинается

1. **`Scripts/Simulation/SimulationCore.cs` → `TickStages`, начало метода.** «Ритм симуляции»:
   что выполняется за шаг, что за день, что по своему расписанию, и почему одно и то же число
   получается при шаге в час и в шесть часов. Это контракт, а не оптимизация.
2. **Там же, начало цикла дня.** «ДЕНЬ, В ПОРЯДКЕ»: двенадцать групп из шестидесяти проходов,
   зачем именно такой порядок, и куда вставлять своё.
3. **`Scripts/Simulation/Defines.cs`, заголовок класса.** Всё про числа: где они лежат, как
   переопределяются, в каких единицах, и почему менять умолчания надо с комментарием, а не с
   желанием.

Порядок дня в коде — **источник истины**. Любая таблица в документации устареет; комментарий
рядом с вызовом не устареет, потому что он там же, где вызов.

## Где что лежит

| Что | Где |
|---|---|
| Числа (баланс) | `game/common/defines/**/*.json`, читаются по алфавиту, поздние файлы побеждают |
| Контент: страны, движения, модификаторы, организации | `game/common/**`, `game/localization/{english,russian}/**` |
| Правила | рядом с собой: файл, который их применяет, и комментарий, который говорит **почему** |
| Проверки | `Tools/FormableTests --<набор>-only`, `Tools/SimBench <дни> <seed> --soak\|--kin\|--wars` |

## Шесть правил дома

1. **Правило живёт вместе со своей причиной.** В комментарии называется дефект, из-за которого
   правило появилось. Правило без причины через год «починят» обратно.
2. **Механизм пишет в состояние, которое читают другие.** Не свой счётчик, а `Radicalism`,
   `Grievance`, `Infiltrated`, `AdministeredById` — тогда он виден на карте, в интерфейсе и в
   ИИ, а не только в своём файле.
3. **Отказ — это предложение.** `Refusal()` возвращает текст, который видит игрок, и тот же текст
   получает компьютер. Кнопка не гасится молча.
4. **Новая система — за флагом** (`MechanicFeatures`, `campaign.FeatureEnabled("...")`), чтобы
   мир можно было включить и выключить без правки кода.
5. **Новое состояние должно попасть в сохранение** (`SaveSystem`), а состояние, которое
   определяет мир, — ещё и в отпечаток (`CampaignFingerprint`). Иначе загруженная партия и
   стенд расходятся, и никто об этом не говорит.
6. **Тяжёлое — под гейт.** `OnItsDay` размазывает решения по странам, `Stages()` режет проход на
   кадры. Проход, поставленный в день без гейта, работает в тридцать раз чаще, чем для него
   настроено.

## Ловушки, за которые этот проект уже заплатил

Каждая — из реального прогона, каждая описана в `docs/`:

- **Одна кость на два решения.** ИИ решал «действовать» тем же броском, которым решалось
  «поймали ли». Действие стало доказательством раскрытия: тридцать операций — тридцать провалов.
  (`KIN_AI_ALWAYS_CAUGHT_2026_10_30_RU.md`.)
- **Постоянная вероятность — это обратный отсчёт.** Шанс раскрытия 3,5 % в неделю означал, что
  учреждение живёт восемь месяцев и всегда умирает; ступень механики не давала ни одного
  выжившего. (`KIN_STATECRAFT_2026_10_29_RU.md`.)
- **Ярлык вместо существа.** «Есть хоть какой-то фронт» держало войну, в которой не было ни боя,
  ни потерь, ни захваченной земли. (`WARS_THAT_NEVER_ENDED_2026_10_30_RU.md`.)
- **Две одинаковые вещи по разной цене.** Белый мир и статус-кво при нулевом захвате — одна и та
  же граница, а принимают 27 % против 77 %. (`Там же`.)
- **Добавление в список, который перебираешь.** Основание страны внутри `foreach` по
  `campaign.Nations` роняет партию; в проекте для этого `campaign.Nations.ToArray()`.
  (`KIN_STATECRAFT_TICK_CRASH_2026_10_29_RU.md`.)

## Как проверить, что не сломал

```powershell
powershell -ExecutionPolicy Bypass -File Tools\dev.ps1 -All       # сборка, тесты, игра
dotnet run --project Tools\FormableTests -- --living-world-fingerprint-only
dotnet run --project Tools\SimBench\SimBench.csproj -c Release -- 1095 1 --soak
dotnet run --project Tools\SimBench\SimBench.csproj -c Release -- 1095 1 --wars
dotnet run --project Tools\FormableTests -- --replay-save "<путь к .bdfsave>" 30
```

Отпечатки — это доказательство, что мир не изменился там, где ты не собирался его менять.
`--replay-save` — доказательство, что партия игрока идёт дальше, а не «должна идти».
