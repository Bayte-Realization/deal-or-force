# Контекстные флаги для моддеров

Флаг — обычный PNG в `gfx/flags`, его имя регистрирует спрайт. Произвольный новый
тег может иметь собственный флаг; он приоритетнее общих запасных вариантов.

## Общегосударственная гражданская оппозиция

У `rising:...` сохранён тег государства, против правительства которого она возникла.
Это не национальное отделение культуры столицы мятежа. Дополнительные варианты:

```
flag_rus_civil_war.png
flag_rus_civil_war_social_democracy.png
flag_rus_civil_war_ukr_social_democracy.png
```

Последний пример появляется только при реальной зависимости от UKR. Квалификатор
`overlord` считывает тег сюзерена лишь когда SubjectType не пуст: старого OverlordId,
союза, поддержки, гарантии или общего противника недостаточно. `subject` отдельно
остаётся типом зависимости. При исчезновении зависимости UI выбирает флаг заново.

Для других стран работает тот же порядок имён; специального списка России нет.
Формабл или явно восстановленная страна сохраняет собственную идентичность.

## Ограничение рисунка конкретным контекстом

В `common/flags/50_my_flags.json` можно объявить:

```json
{
  "flag_context": {
    "flag_my_protectorate": {
      "requires": { "overlord": ["GBR", "FRA"], "subject": "protectorate" },
      "otherwise": "flag_my_independent"
    }
  }
}
```

Все поля requires должны выполняться одновременно; значения массива — альтернативы.
Используются известные источники FlagCatalog (ideology, government, culture, continent,
war, tag, focus, formable, revolt, subject, overlord). Неизвестный источник сообщает
об ошибке загрузки, а не становится всегда истинным. Сравниваются реальные значения,
не отображаемые локализованные названия. Без otherwise запрещённый кандидат пропускается.
Цепь замен ограничена; цикл в моде не блокирует игру.

Чтобы убрать ограничение нижележащего пакета:

```json
{ "flag_context": { "flag_my_protectorate": { "requires": {} } } }
```

Правила не делают страну зависимой и не создают отношения. Они только выбирают
изображение по существующему состоянию. Править нужно условия рисунка, а не выдавать
всем временным правительствам колониальную символику.

## Цвета отделений

`common/defines/89_secession_colours.json` содержит SecessionColourPalette — массив
`#RRGGBB`. Предпочитается различимость от родителя и соседей, культурный цвет
сохраняется когда он достаточно отличим. Новое значение сохраняется в Nation.Color.
MigrateLegacySecessionColoursOnLoad можно отключить; миграция касается только точной
старой формулы, только локальной загрузки, не сетевых snapshot и не перезаписи файла.
