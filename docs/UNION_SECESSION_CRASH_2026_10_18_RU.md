# Остановка симуляции при распаде союза — 18.10.2026

## Подтверждённая причина

Пользовательская кампания остановилась 12 июня 2055 (день 11485).
errors.log сохранил исходный стек InvalidOperationException:
Collection was modified; enumeration operation may not execute,
UnionCohesion.Tick, строка 109 → Campaign.TickStages → RunStages → _Process.

UnionCohesion перебирала campaign.Nations через foreach. Во время этого обхода
LoseTheAngriestRegion → SecessionEvents.Force → Found → AddNation добавляла
новое государство в тот же List. Следующий MoveNext бросал исключение.
Защитная блокировка не является причиной: она не дала перезаписать хороший
сейв частично выполненным днём. Отключать её и возобновлять повреждённый шаг нельзя.

## Узкое исправление в общем рабочем дереве

Обход фиксирует количество стран в начале прохода и использует индексы.
Campaign сохраняет Id == index; эта цепочка только добавляет страны и не удаляет
старые элементы. Новые страны начинают обрабатываться со следующего прохода.
Нет изменяемого enumerator и нет ежедневной аллокации ToArray.
Распад, перераспределение ресурсов, война/ответ и cooldown не отключены.

Это локальная правка в ещё не опубликованном параллельном блоке UnionCohesion.
Чужая механика целиком не переносилась в изолированную публикационную копию.
Для публикации этого блока нужно включить правку вместе с его зависимостями,
а не затереть файл старой версией.
