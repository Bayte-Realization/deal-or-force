# Интерфейс кампании и формируемые государства

## Что изменилось

Повторяющийся рисунок стола с картой удалён из стандартного досье. Он не показывал сведений о выбранной стране, занимал 86 px по высоте и конкурировал с картой. Звёздная текстура за глобусом по умолчанию отключена: используется спокойный цвет `shell.space`. Файлы изображений сохранены, поэтому изменение обратимо. Флаги, значки функций, сама карта и иллюстрации главного меню не удалены.

Из решений убрана ссылка «What it would cost», из дипломатии — переход к собственным политическим настройкам. Управление своей страной находится на вкладке её правительства; чужое досье не предлагает управлять чужим правительством. Бюджет больше не дублирует региональную демографию. Заблокированные настоящие действия (например, решение на перезарядке) остаются с объяснением причины — это не пустые кнопки.

## Где редактировать

| Файл/каталог в `game` | Что контролирует |
| --- | --- |
| `gui/10_campaign_shell.json` | Расположение и размеры панелей, якоря и отступы |
| `gui/20_campaign_structure.json` | Состав и порядок главных показателей, навигация, вкладки, ссылки и условия видимости, порядок/скрытие групп сводки |
| `gui/21_dossier_contents.json` | Порядок, скрытие и подписи информационных строк досье |
| `interface/` и `gui/`, секции `colors`, `metrics` | Цвета, размеры кнопок/вкладок, внутренние отступы, спокойный фон |
| `common/formable_nations/` | Новые государства, основатели, территории, стоимость и бонусы |
| `localization/russian/32_formable_nations.json` | Русские подписи механики |

Файлы JSON загружаются по имени; позже загруженное значение перекрывает предыдущее. Моды используют такие же пути **от корня мода**, без дополнительной папки `game`. После изменения перезапустите игру. Перекомпиляция C# не нужна. Это не live-редактор: уже созданное дерево окон автоматически по каждой правке файла не перестраивается.

Массивы заменяются целиком. Отсутствующее свойство наследуется. `[]` явно удаляет все элементы массива. `detail_labels` объединяется по ключам. Не копируйте весь исходный файл ради изменения одного свойства.

### Пример компактного HUD

```json
{
  "campaign": {
    "top_stats": ["TREASURY", "BALANCE", "STABILITY", "MANPOWER"],
    "outliner_order": ["CONSTRUCTION", "MARKET", "WARS", "BATTLES", "NAVY", "WATCHLIST"],
    "hidden_outliner": ["BATTLES"],
    "screens": {
      "Nation": {
        "hidden_details": ["GDP per head"],
        "detail_labels": {"States held": "Административные регионы"}
      },
      "Diplomacy": {"links": []}
    }
  }
}
```

`detail_order` — ключи строк в порядке отображения. Заголовок имеет префикс `#`: `#STATE`, `#ECONOMY`. Неупомянутые строки сохраняются после перечисленных. Для удаления используйте `hidden_details`. Ключ — исходная английская подпись до локализации. Значение строки вычисляет симуляция, оно не подменяется текстом из JSON. При изменении порядка переносите заголовки вместе со строками соответствующего раздела.

### Вкладки и ссылки

Навигационные экраны: `Nation`, `Economy`, `Military`, `Diplomacy`, `Wars`, `Decisions`, `State Affairs`, `Ledger`. Их можно переставлять, убирать, переименовывать через `label` и менять `icon` (суффикс имени `icon_…`).

Доступные обработчики вкладок:

- `Nation`: `Overview`, `Government`, `Society`; `groups` задаёт видимые группы (`STATE`, `ECONOMY`, `GOVERNMENT`, `SOCIETY`). Пустой `groups` показывает все группы.
- `Economy`: `Budget`, `Market`, `Construction`.
- `Region`: `Overview`, `Population`, `Province`.
- `Decisions`: `Decisions`, `Formables`.

Ссылка: `label`, `action`, необязательные `tab`, `context`, `help`. Обработчики: `government`, `ledger`, `wars`, `diplomacy`. Контексты: `always`, `own`, `foreign`. Неизвестные действия не создают кнопок; ошибки модов сообщаются загрузчику. Доступ к чужому правительству блокируется дополнительно в коде, даже если мод неправильно настроил контекст.

## Формируемые государства

Открытие: **Решения → Формируемые государства**. По умолчанию показаны только варианты своей страны; переключатель открывает справочный список остальных без неуместных кнопок провозглашения.

В `00_unions.json` шесть вариантов: Объединённая Корея, Центральноазиатский союз, Союз Бенилюкса, Северный союз, Иберийский союз, Балтийский союз. Дополнительные файлы каталога расширяют список, включая исторические проекты. Это альтернативно-исторические игровые проекты, не описание существующих государств.

Условия общие: подходящий основатель, мир, достаточная стабильность и казна, полное владение **и** контроль необходимых сухопутных провинций. Временная оккупация не подходит. Другая страна не должна уже провозгласить тот же проект. Каждая страна может сформировать одно государство за кампанию. Перед списанием суммы требуется подтверждение; команда повторно проверяет условия.

```json
{
  "my_union": {
    "name": "Мой союз",
    "description": "Описание нового государства и его идеи.",
    "eligible_tags": ["BEL", "NLD"],
    "required_tags": ["BEL", "NLD", "LUX"],
    "minimum_stability": 0.70,
    "gdp_cost_share": 0.02,
    "governance_gain": 0.04,
    "productivity_gain": 0.015
  }
}
```

`required_tags` означает территории **исходного активного сценария** из `history/provinces`, а не оставшиеся земли страны после ваших завоеваний. Учитываются модовые изменения исходной карты. Для собственного точного набора можно использовать `required_provinces: [123, 456]`; списки объединяются. Неизвестная страна или несуществующая провинция блокирует формирование, а не облегчает требования. Морские/озёрные провинции не требуются. Числа условий/бонусов лежат в диапазоне 0…1. Поздний файл может изменить отдельные свойства проекта; `{"my_union":{"disabled":true}}` удаляет его из каталога.

Провозглашение меняет имя, записывает ID проекта и день, списывает стоимость и разово повышает накопленный вклад управления/производительность. Вклад управления ограничен `common/stability` и затем подчиняется обычному затуханию; это **не постоянный множитель**. Строй, ID страны, войска и дипломатические связи сохраняются. Флаг выбирается общим `FlagCatalog`, включая признак `formable`: при наличии подходящего ассета он изменится. Территорий и бесплатных аннексий действие не добавляет. Идентичность входит в сохранения и сетевые снимки; команда поддерживает общий сетевой кодек. Самостоятельный выбор таких проектов ИИ пока не добавлен.

## Иконки и флаги политических вариантов

Для всех 12 базовых идеологий есть авторские векторные символы в `game/gfx/interface/ideologies/`. Имя файла — `icon_ideology_<id>.svg`. Мод может положить в своё `gfx/` файл с тем же именем спрайта и расширением SVG **или PNG**: перекомпиляция и JSON не требуются. Для новой идеологии без собственного изображения используется `icon_ideology_generic`. Для изменения размеров/пропорций самого рисунка редактируйте SVG в Inkscape или заменяйте PNG с прозрачностью. Это условные игровые символы, а не универсальные официальные эмблемы идеологий.

Политика показывает отдельный флаг для каждой идеологии и каждой формы правления. Предпросмотр вызывает обычный `FlagCatalog.Resolve` на копии политических полей: страна, война, культура и сформированная идентичность сохраняют контекст. Кампания не изменяется. Если результат совпадает с действующим флагом, написано «Флаг не изменится». Правила алиасов, сочетаний и приоритетов остаются в `game/common/flags`, изображения — в `game/gfx/flags`; модовые переопределения применяются и к предпросмотру, и к принятому варианту. После замены ассетов в работающем редакторе дождитесь импорта и перезапустите игровую сцену.

## Сетевое лобби

Два блока из `game/gui/22_multiplayer.json`: `multiplayer.connection` и `multiplayer.countries`. Координаты, размеры и привязки заменяются модом; фон использует общие `shell.*` цвета. Середина экрана не перекрывает глобус.

Выбор страны работает кликом по её территории или поиском по локализованному имени/тегу. Правая кнопка вращает глобус, колесо меняет масштаб. Армии и бои в режиме выбора не перехватывают клик по стране; военные приказы из лобби не отправляются. Сервер подтверждает резервирование: занятую страну больше не заменяют другой молча. Всем клиентам передаются имена игроков, страны и готовность. При изменении страны/состава готовность сбрасывается; запоздалые подтверждения предыдущего состава отклоняются. Для старта нужно минимум два зарегистрированных и готовых игрока с разными странами. Во время кампании смена уже назначенной страны запрещена; прежний путь позднего входа нового игрока со снимком кампании сохранён.

Протокол лобби изменён: всем участникам нужна одна версия игры и одинаковые моды. Это прямое ENet/IP-подключение, не Интернет-поиск серверов: firewall, маршрутизация, VPN и проброс UDP остаются необходимыми в зависимости от сети. Порт проверяется явно (1024–65535).

## Что остаётся в коде

Основная оболочка кампании, информационные строки и выбор готовых действий теперь управляются данными. Это **не перенос всего интерфейсного движка**: расчёты значений, обработчики, сложные внутренности военных/мирных окон, настройка бюджета и универсальные компоненты остаются C#. Добавить принципиально новый вид действия или новый интерактивный компонент одним JSON пока нельзя. Это ограничение сделано явным, чтобы моды не получали кнопки с выдуманными неработающими командами.

Проверки: `dotnet run --project Tools/FormableTests/FormableTests.csproj` — загрузка/наложение UI, контексты, разрешение территорий, отказ по условиям, повторная проверка команды, стоимость, отсутствие аннексии, повторное нажатие, сетевой кодек и сохранение/загрузка.
