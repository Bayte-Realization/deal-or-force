# Сценарии, мастерская и подписи карты

## Как открыть

Главное меню → «Одиночная игра» → «Сценарии и мастерская».
Выберите сценарий, затем страну непосредственно на карте. Из выбора страны
можно вернуться кнопкой «Сценарии / редактор».

«Создать сценарий из этого мира» сохраняет независимую копию текущей кампании.
Это именно копия: изменение даты не превращает современные населения, экономики
и границы в исторически достоверный мир. Их нужно отредактировать отдельно.

## Формат сценария

`game/scenarios/<id>/scenario.json` или та же структура в моде:

```json
{
  "id": "my_world",
  "name": "Мой мир",
  "description": "Описание авторского сценария",
  "world": "world.json"
}
```

`world.json` — полный читаемый снимок: Date, Nations, States, Armies, Fleets,
Wars, отношения, политические слои ProvinceOwner / ProvinceController /
ProvinceState / ProvinceOccupation, ScenarioRules и ScenarioTerritories.
Проще создать его кнопкой, чем вручную составлять десятки тысяч записей.
Ссылки между сущностями используют стабильные числовые IDs. Массивы провинций
включают нулевой служебный элемент. Геометрия карты и её версия должны совпадать.

ScenarioTerritories хранит исходные территории тегов для требований формируемых
государств. Они не подменяются современными границами в авторских сценариях.
Дата сценария независима; ElapsedDays сохраняет начало отсчёта внутренних сроков
приказов и событий. Не обнуляйте его без пересчёта связанных сроков.

Только встроенный сценарий `2024` без world-файла использует прежний современный
генератор. Полные сценарии не вызывают его и не получают современные армии,
войны, историю стран или исправления границ при загрузке. Современный генератор
пока остаётся в C#: вся его исходная география ещё не перенесена в один world.json.
Сохранения и сетевые снимки сохраняют идентификатор сценария, а авторские — также
его правила. Старые сохранения без идентификатора считаются сценарием 2024.

## Мастерская данных

Редактор показывает базовые JSON-документы, затем наложения включённых модов и
вашу рабочую копию. Поиск фильтрует пути. Наведите курсор на файл, чтобы увидеть
его полный путь и источник. Поддерживаются common, history, scenarios, gui,
interface, localization, fonts, sound, music, gfx и map_data.

Вкладка «Свойства»: выберите значение, введите число, true/false или строку
в кавычках и нажмите «Применить свойство». Дерево ограничено шестью уровнями,
первыми 100 элементами каждого массива и 4000 узлами для устойчивой работы.
Полный документ, добавление/удаление элементов и контейнеры доступны на вкладке
JSON. Ctrl+Z/Ctrl+Y отменяют/повторяют изменения. «Новый документ» создаёт
редактируемый черновик по указанному пути; запись произойдёт только по «Сохранить».

Сохранение идёт в `user://mods/editor_workspace`, не в исходную игру.
Перезапись атомарная; предыдущая версия остаётся рядом в `.bak`.
Недопустимые пути и перенаправленные файлы/каталоги отклоняются.
«Проверить» проверяет JSON, а для снимков сценария — также версию карты и основные
ссылки. Это не полная проверка семантики всех каталогов: загрузчики отдельных
подсистем дополнительно проверяют свои поля при запуске.

Включите **Editor workspace** в выборе модов и перезапустите для изменений
правил и UI. Сценарии из рабочей папки видны в библиотеке сразу. Редактор не
исполняет код из текста и не перезагружает произвольные скрипты автоматически.

Это первый рабочий редактор данных, а не законченный визуальный редактор всего:
пока нет кисти изменения геометрии провинций, визуального конструктора виджетов,
редактора растров, CSV-таблиц или мастеров всех типов сущностей.

## Названия стран и шрифты

Для страны RUS: `country.RUS.name` — полное название, `country.RUS.map` — подпись
карты. Для сформированного государства: `formable.<id>.name` и `.map`.
Ищутся от наиболее конкретного к общему:

1. `.government.<government>.ideology.<ideology>.name` / `.map`;
2. `.government.<government>.name` / `.map`;
3. `.ideology.<ideology>.name` / `.map`;
4. `.name` / `.map`.

Без специального ключа работает перевод исходного названия страны. Существующая
русская таблица `20_countries.json` сохранена. Короткие подписи США, КНДР и т.д.
добавлены в `34_workshop.json`. Не меняйте теги ради переименования.

Типографический профиль «Globality Atlas»: спокойный интерфейс без засечек и
разреженные картографические подписи с засечками. Это не новый авторский TTF.
`game/fonts/00_fonts.json` задаёт роли `ui.default` и `map.countries`.
`system_families` запрашивает установленный шрифт; для одинакового вида на всех
ПК положите лицензированный TTF/OTF в мод и задайте `file` для роли.

## UI и читаемость границ

В `game/gui` уже доступны раскладка панелей, навигация, вкладки, поля досье,
контекстные ссылки, статистика, сводка и лобби. Мастерская редактирует эти же
документы. Движковые обработчики остаются в C# — данные выбирают поддерживаемые
действия, но не превращаются в произвольные вызовы методов.

`24_workshop.json` добавляет положение мастерской и метрики:

- `map.country_font_size`, `map.country_tracking` — подписи;
- `map.province_border_width` — толщина близких границ в экранных пикселях;
- `map.province_border_opacity` — контраст 0–1;
- `map.province_border_halo` — светлая обводка для тёмного рельефа.

Провинциальные линии плавно проявляются при приближении; на общем плане
подавляются. Границы стран и фронтов сохраняют собственное оформление.

## Наступления

Выберите дивизии → «Фронт»: ЛКМ по всей границе или ПКМ по участку →
«Наступление»: проведите ПКМ линию назначения внутри страны противника →
«Выполнять». «Подготовка» останавливает выполнение; Alt+ПКМ перерисовывает цель.
Пустая провинция под сильным огневым прикрытием соседей может задерживать приказ:
это действующая зона контроля, а не потеря нарисованного маршрута.

Проверка наступления отдельно:
`dotnet run --project Tools/ArmyInteractionTests -- --offensive-only`.
Проверка сценариев, флагов и записи редактора:
`dotnet run --project Tools/FormableTests`.
