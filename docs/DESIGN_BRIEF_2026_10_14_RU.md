Проверка: `FormableTests --ui-icons-only` = 141 PASS / 0 ошибок парсинга; JSON валиден
для движка (`//`-комментарии внутри `metrics` корректно скипаются `StructuredData`).

**Второй шаг (14.10.2026):** тот же приём распространён на
- нижнюю полосу режимов карты (`MapControlsUI.cs` → `map.controls_flow_h_gap`,
  `map.controls_flow_v_gap`, `map.controls_button_height` в `game/gui/38_flat_map.json`);

Паттерн устоялся: находим магическое число в `Scripts/ui/*.cs` → именуем токен в
`game/gui/*.json` → читаем через `Ui.Metric(токен, текущее)` → проверяем стендом.

## 5. Реставрация исчезнувших стран (ID-04)

**Замысел.** Страна, что была на старте (1.01.2024) и исчезла, остаётся в «архиве
мира» со своей идентичностью (культуры, религии, флаг, историческое ядро). Её можно
восстановить **законно** — если есть носитель (правительство в изгнании / движение /
формация) и материал (территория + население + ресурсы), без «кражи контроля» и без
дубля тега.

- **Состояние (сериализуемо):** `ScenarioState.LegacyIdentities[id] = { tag, cultures,
  religions, flag, homelandProvinces, goneDay }`.
- **Пути:** мирный — формировка (§3.3) с `restores: "<legacy_tag>"`; военный — движение
  с контролем исторического ядра провозглашает страну.
- **Защиты:** нельзя восстановить поверх чужого живого контроля без соответствия
  населения; нельзя дважды (тег занят); `fingerprint`/`split/merge` учитывают архив.
- **Проверка:** `FormableTests -- --restoration-only` — восстановление, save/load,
  отказ при NaN, отсутствие двойного тега.

Пример (в `formable_nations/50_identity_paths.json`):
```json

  "restore_ryukyu": {
    "name": "Ryukyu",
    "description": "The old kingdom, restored to independence. Its people still live where they always did.",
    "eligible_tags": ["JPN"],
    "restores": "RYU",
    "required_provinces": ["okinawa", "amami"],
    "minimum_stability": 0.55, "gdp_cost_share": 0.020,
    "governance_gain": 0.03, "productivity_gain": 0.015, "colour": "#c85f7f"
  }
```

## 6. Уязвимость гегемонов (BAL-01, CRISIS-04) — без штрафа «по тегу»

**Принцип (твой же):** США/Китай не должны быть неуязвимы, но и **не** распадаться по
нажатию. Развал — следствие накопленных причин (долг, лёгкие деньги, легитимность,
региональные коалиции, внешнее давление), а не случайного RNG или штрафа за тег.

- **Гражданско-федеральный путь (CRISIS-04):** сейчас `ForeignShare < 0.55` режет
  сепаратизм многокультурных регионов. Ввести **отдельный** маршрут: федеральный регион
  со **своей** идентичностью (напр. Калифорния, Техас) при высокой идеологической
  дивергенции + слабой легитимности центра + экономическом кризисе может пойти по
  «штатному» сценарию. Никакого искусственного ethnic-shift.
- **Экономическая уязвимость (связка с ECO):** дефицит, госдолг, ключевая ставка,
  отток производства → падение реального выпуска → безработица → давление на
  институты. У тебя это **уже смоделировано снизу вверх** — надо дать долгому горизонту
  накопить последствия (20–100 лет), а не гасить мгновенно.
- **Внешнее давление (BAL-02):** оплаченные интриги, санкции, поддержка региональных
  движений — с ценой, риском и **следом** (дипломатический скандал, рост напряжения).
- **Проверка:** `SimBench` на 20–100 лет, множество сидов; причина видна до вспышки
  (ранняя шкала), а не «внезапно распалось».

## 7. Идеологическое деление населения (POL-01)

**Замысел (твой тезис):** население делится не только по культуре/религии, но и по
**идеологии, отношению к законам, форме правления, экспансии и качеству жизни**. Это
рождает когорты, чьё несогласие → нестабильность, сепаратизм, перевороты, скандалы.

- **Состояние:** `ScenarioState.PoliticalCohorts[region] = { ideologyShare, lawApproval,
  govApproval, expansionStance, qolExpectation }` — ограниченно, сериализуемо.
- **Динамика:** когорты дрейфуют медленно к условиям (налоги, войны, обещания, качество
  жизни — из household-экономики). Не мгновенно.
- **Последствия (переиспользуем существующее):**
  - низкий `lawApproval` → радикализм (→ `DomesticCrises`, движения);
  - низкий `govApproval` + внешний шок → `CoupPressure`;
  - идеологический разрыв центр↔регион → шанс `Secession`/гражданско-федеральный путь;
  - давление режима по несогласным → **скандал** (reputation-модификатор, POL-02).
- **UI:** график «политическое население» (UI-08) — поверх реальной модели, не декор.
- **Проверка:** `--political-only` регрессии; fingerprint и split/merge хранят когорты.

Пример (`defines/70_political_cohorts.json`):
```json
{
  "Features": { "political_cohorts": true },
  "CohortDriftPerDay": 0.002,
  "LawDisapprovalRadicalism": 0.35,
  "GovDisapprovalCoupPressure": 0.20,
  "CenterRegionIdeologySplitSecession": 0.55,
  "RepressionScandalChance": 0.02
}
```

## 8. Движения как грозная сила (MOV-01/02)

Усилить существующее (мирная агитация ↔ радикализм ↔ насилие): по мере роста
признания/ресурсов движение получает **больше реальных возможностей** — международный
голос, спонсоров, контроль территорий, влияние на экономику региона. Каждая — с
пределом и объяснением. Новые регионы сохраняют людей/производство/долг.

- **Возможности по уровням:** признание → мирные сделки → спонсоры → военное крыло →
  контроль региона → провозглашение страны (§5).
- **Пределы:** раскрытие контрразведкой, санкции против спонсоров, потеря легитимности
  при насилии над мирными.
