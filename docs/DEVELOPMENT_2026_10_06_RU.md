## Ограничения диагностики

Fennara привязан явно к копии 4.8. Его LSP-preflight всё ещё пытается
подключаться к порту 6005, хотя редактор 4.8 слушает 6006, а 6005 занят
редактором 4.7. В самом редакторе 4.8 установлен порт 6006; 4.7 не менялся.
Общий диагностический скан не дал результата в поддерживаемое время,
поэтому не объявляется пройденным. Нативный C# build и прямой runtime
использованы как независимые проверки.
Позже восстановлена запись завершения скана через 1 215,884 секунды:
сохранённый `result` пуст (`{}`), поэтому она не подтверждает отсутствие
ошибок. Повторный широкий скан не запускался.

Ранний тест с пользовательским SceneTree вызывал ошибки GD-Sync из-за
отсутствия текущей сцены. Повторный тест использует обычную авторскую сцену
и штатный запуск. GD-Sync Logger при standalone-запуске без debugger
всё равно пытается отправить debugger-сообщение: это отдельное оставшееся
ограничение аддона. Аддоны и инфраструктура Fennara не переписывались.

По запросу пользователя отдельно прочитан полный Output редактора 4.8:
3 793 одинаковых `net_socket_winsock.cpp:561 / !is_open() / -1`,
8 обращений к отсутствующей теме подсветки Dialogue Manager и один вызов
`BeginSession` из раннего редакторского теста. Последний тест перенесён
в настоящий runtime. Два последовательных снимка Output показывают
одинаковые 3 793 записи, то есть между измерениями сетевой счётчик не рос.
Виновник сетевого вызова пока не установлен: эти строки не содержат
стека аддона. Ошибки не очищались и плагины не выключались.

Сборка здесь означает локальную Debug-компиляцию. Экспортный архив,
релиз, push и публикация бинарников на GitHub в этом этапе не выполнялись.
