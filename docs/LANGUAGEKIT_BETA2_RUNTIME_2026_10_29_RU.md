# Языковой комплект Beta2 — реальная проверка 29 октября

Основная установленная папка не изменилась:
`C:\GodotEngineNet 4.8-Beta2\LanguageKit`.
Исходники для репозитория — `LanguageKit/` в основном проекте.
Компиляторы — `.cache/toolchains`, проверочные проекты —
`.cache/verified-beta2`, отдельные старые источники — рядом в
`C:\GodotEngineNet 4.8-Beta2\LanguageKit-backups` с квитанциями SHA256.
Бинарники движка, существующий AllSix и игровые addons не заменялись.

Три связки действительно пересобраны и вызваны в
`4.8.beta2.mono.official.cafc17a19`: Rust gdext 0.5.5, Zig gdzig и Go
graphics.gd. Импорт редактором, настоящий метод и завершение — exit 0.
У Zig/Go проверены знаки, ноль и число **4294967297**, выходящее за 32 бита.
Rust проверяет signed/empty PackedInt32Array через API, сгенерированный
именно Beta2. Системный Go остался 1.21.4; переносимый — 1.27.3.
Rust — 1.99.1, Zig — 0.17.0. Вето владельца на Rust снято.

Python не выдан за готовый: py4godot 4.7-alpha21 с CPython 3.14.4
выполняет небольшой пример, но проваливает границу int64 и очистку при выходе.
Проверка завершается ошибкой, несмотря на успешные маленькие числа. Этот
аддон оставлен в отдельном экспериментальном проекте и не включён в игру.

Дополнительная ссылка владельца также обработана: ветка
`touilleMan/godot-python/godot4-meson`, HEAD `4f585652` от 26 февраля.
Исправлены три несовместимости её парсера с API Beta2: новые compatibility
hashes методов, новые глобальные целочисленные константы и необязательные
описания. Сохранены данные и строгая проверка неизвестных полей. Восемь
регрессионных тестов зелёные; весь API прочитан в четырёх раскладках памяти.
Полная нативная сборка этого порта, экспорт, жизненный цикл и выдача новых
констант в пользовательский API пока не проверены.

Добавлены закреплённые контрольные суммы переносимых компиляторов,
локальная сборка без изменения постоянного PATH, проверка копируемых шаблонов,
изолированные пробники и обновление установленного комплекта с резервными
копиями. Doctor отличает прежний результат Beta1 от настоящего результата
Beta2. Наличие системного исполняемого файла не означает подходящую версию.

Матрица результатов и точные команды:
[отчёт комплекта](../LanguageKit/reports/beta2-runtime-2026-10-29.md).
Проверены контракты шаблонов/путей и исключение всего LanguageKit из настоящих
Compile/Content/None игры. Скорость тика, визуал игры, экспорт и сохранения
этим проходом не менялись. Ускорения в «пять раз» не заявлены.

Остальные языки и godot-sandbox сохраняют прежние датированные результаты
Beta1: их нельзя считать повторно принятыми на Beta2 лишь из-за новой подписи.
Rust/Zig разумны для измеренных пакетных ядер; Go — для инструментов и
отдельно обоснованных сервисов; Python — для анализа, проверок и офлайн-данных.
Авторитет кампании и сохранений остаётся единым. Планы игры продолжаются;
данный ограниченный срез не объявляет законченной всю переработку проекта.
