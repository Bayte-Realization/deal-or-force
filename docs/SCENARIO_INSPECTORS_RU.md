# Инспектор сценария и безопасная правка данных

Открывается в отдельной сцене редактора карты кнопками «Изменить страну…» / «Изменить регион…». Работает с черновиком, не меняя текущую партию.

Сохранённые сценарии теперь можно повторно открыть на карте прямо из библиотеки.
Правила копирования, резервных копий и конфликтов описаны в [рабочем процессе сценариев](SCENARIO_REOPEN_RU.md).

## Рабочий процесс на карте

Боковая панель разделена на «Цель кисти» и «Выбранная территория». Щелчок в режиме выбора показывает провинцию, но не переключает цель окрашивания. Кнопка «Взять цель кисти с карты» выбирает страну и регион этой провинции; она не включает кисть и не изменяет карту. Из выбранной территории можно сразу открыть инспектор её страны или региона. Для воды и отсутствующих записей действия недоступны. Боковая панель прокручивается независимо от карты; длинная инструкция перенесена в «Управление и возможности».

## Настройки сценария

«Настройки сценария…» открывают название, описание, дату (год / месяц / день / час) и положительный целочисленный сид. Название и описание сохраняются в `scenarios/<id>/scenario.json`, дата и случайное состояние — в `world.json`. Это документы сценария, а не новый формат сохранения партии.

Изменение настроек — одна операция общей истории Undo/Redo. Неверная календарная дата не применяется. Смена календарной даты не обнуляет `ElapsedDays`: сроки приказов, решений и событий не переписываются. Название, описание и дата также не сбрасывают случайную последовательность. Только изменение сида создаёт новый `SimRandom`; отмена восстанавливает прежнее состояние точно. Перед началом кампании выбор сида по-прежнему может переопределить записанный сид. Это не генератор исторического мира: перенос даты не создаёт автоматически население, технологии и армии другого века.

Календарь учитывает високосные годы, включая исключение веков, не делящихся на 400.

## Обычные поля

Название, цвет карты, форма правления и идеология; численность населения, ВВП и казна (в миллиардах), грамотность, стабильность, поддержка войны и региональный радикализм. Политический предпросмотр использует тот же выбор флагов, что сама игра, в отдельной копии мира.

Вкладка свойств прокручивается; диалог ограничен размером экрана. Неизменённые числа не переписываются через SpinBox, поэтому открытие вкладок не должно округлять исходные значения. JSON остаётся доступным для всех остальных полей.

Численность страны — исходная сводная цифра, а не инструмент перераспределения населения между её регионами. При дальнейшей симуляции она пересчитывается из регионов. Изменение численности региона не перераспределяет его группы населения автоматически. Для согласованного сценария нужно также проверить PopulationGroups и экономические записи в JSON.

## Модифицируемые формы

`game/common/editor/00_scenario_inspector.json` описывает поля отдельно для `country` и `region`. Мод кладёт свой JSON в `common/editor`, поздние файлы дополняют существующие записи. Пример:

```json
{
  "country": {
    "Stability": { "label": "Government legitimacy (%)", "order": -1 },
    "WarSupport": { "hidden": true },
    "EducationSpending": {
      "label": "Education budget (%)", "min": 0, "max": 100,
      "step": 0.1, "scale": 100, "order": 10
    }
  }
}
```

Поддерживаются существующие публичные поля модели типа float и long: `label`, `min`, `max`, `step`, `scale`, `order`, `hidden`. Проценты отображаются через scale=100, в JSON остаются долями. Подписи переводятся обычными таблицами localization. Поля ID нельзя превратить в числовой контрол. Представление не отменяет правил модели: отрицательное население, NaN, переполнение float, проценты вне 0–1 и неизвестная политика не принимаются. Отрицательная казна допустима.

`order` — целое число в диапазоне Int32; `hidden` — только true / false. Некорректные объявления диагностируются, а проверка документа не меняет работающий каталог.

Размеры боковой панели, списка стран и инспекторов вынесены в `game/gui/37_scenario_editor.json`. Мод переопределяет те же ключи в своей папке `gui`. Размеры окон дополнительно ограничиваются доступным экраном. Цвета и стиль кнопок наследуются от общего интерфейса игры, без отдельной темы редактора.

## Сохранность

- Ошибочный JSON или неудачный переход между вкладками не должны заменять введённый буфер предыдущей версией. Исправить ошибку можно на той же вкладке.
- Инспектор защищает ID, Tag, Iso и ссылки владения; не допускает незаметного удаления ранее сохранённых полей. Для намеренного удаления произвольных полей существует общий редактор содержимого.
- Правки сущности входят в общую историю Undo/Redo с рисованием владения. Фильтр стран и выбранный регион сохраняются при обновлении списка.
- Общий редактор позволяет вводить многострочные значения объектов/массивов. Он восстанавливает выбор поля и раскрытые узлы, проверяет актуальность документа перед подтверждённым удалением, не меняет путь сохранения при неудачном открытии файла и обновляет список после записи. Ctrl+S сохраняет из всех его вкладок.
- Escape в редакторе карты сначала отменяет незавершённый мазок/перемещение; дочерние окна получают собственные клавиши и не должны закрывать весь редактор.

Проверка логики: `dotnet run --project Tools/FormableTests/FormableTests.csproj`. Проверка реальных окон и маршрутизации клавиш пока заблокирована диагностическим подключением GDScript LSP на 6005; кодовая проверка не заменяет визуальный прогон.
