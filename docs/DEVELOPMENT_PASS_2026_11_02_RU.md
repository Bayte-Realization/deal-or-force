# Проход разработки — 2 ноября 2026

## Единственный вариант для Кыргызстана

В «Настройки → Интерфейс», после двух прежних шуток о названиях стран, добавлен
`country_name_kgz`. Английская и русская истории из запроса сохранены дословно.
Единственный вариант и значение по умолчанию — `kyrgyzstan`, подпись
«Кыргызстан / Kyrgyzstan». Общий CountryNames читает вариант и для карты, и для
карточки; отдельного обработчика в UI нет. Форма государства, сформированные
государства и явно введённое игроком имя сохраняют прежний приоритет.

Изменение — данные и локализация. Игровой C# не менялся; в тестовый стенд
добавлены проверки значения, переводов, порядка, хранения и имён.
`dotnet run -c Release --project Tools/FormableTests/FormableTests.csproj -- --country-name-settings-only`:
**16 PASS**, exit 0. Накопленные настройки проверены на собственной временной
папке, не на предпочтениях пользователя. Чтение и запись выбора не меняют
fingerprint/RNG кампании; неподдерживаемое старое значение возвращается к
единственному доступному варианту, пользовательское имя страны не затирается.

Аудиты локализации EN/RU: конфликтов 0, несовпадений placeholders 0, пустых
значений 0. Логи — `tmp_logs/kyrgyzstan-setting-*-20261102.log`.

Визуальный прогон окна не выполнялся: редактор и игровая сессия пользователя
оставлены работающими. Компоновка SettingsRows не менялась. Полный стенд,
SimBench, экспорт/упаковка и публикация не запускались. Уже запущенная игра
получит новую строку после перезапуска либо перезагрузки каталога настроек.
