# Языковые участки: проверка реальной пользы — 16 октября 2026

## Решение и постоянный набор

Сохраняем **Luau, F#, Nim, Odin, Rust, Kotlin** как комплект разработки,
[с уровнями поддержки](LANGUAGE_BACKENDS_RU.md), а не шесть обязательных runtime
игры. Rust — только для редких сложных задач, где измеренная польза оправдывает
сопровождение. Повседневная логика, состояние мира, команды, save и сетевая
авторитетность остаются в C#; форк исполняемого файла Godot не делался.

## Odin и Rust: связность владений

Созданы независимые реализации одного C ABI v1: упорядоченный обход CSR-графа,
входы из примитивных буферов, полный выход за один вызов. Native-функции не
удерживают указатели или мир, не выделяют собственную очередь; scratch даёт
вызывающий код. Проверяются размеры, CSR, water flags, выравнивание, alias,
capacity и адресная арифметика. Сохраняются точный BFS-порядок, порядок соседей,
исключение воды/нулевого владельца и нулевые хвосты.

C#-host грузит только явно указанную абсолютную библиотеку с ABI v1, проверяет
выход, при отказе отключает backend и пересчитывает всю партию managed.
Это защита контракта доверенного кода, не OS-песочница: ни исключение .NET,
ни Rust catch_unwind не спасают от любого native crash/abort/зависания.
Odin status 3 означает явный внутренний отказ, не универсальный panic catcher.

Стенд сравнивает с существующим all-owner C# BFS, а не с заведомо дорогим
повторным сканированием для каждой страны. Измерение включает упаковку water,
pinning/ABI, native-проверки, проверку результата и одинаковые HashSet/rim/pore
индексы. Построение CSR считается отдельно; польза прежнего кэша не приписана
новому языку. Выходы сверяются вне измеряемого участка.

| Полный проход, p50 / p95 мс | Существующий C# | Native | Выборка |
| --- | ---: | ---: | --- |
| Реальная карта, Rust | 2,629 / 6,029 | 3,657 / 4,583 | 51 |
| Реальная карта, Odin | 2,729 / 5,710 | 3,931 / 4,993 | 51 |
| Синтетическая 512 вершин, Odin | 0,026 / 0,032 | 0,049 / 0,062 | 25 |
| Синтетическая 300 000 вершин, Odin | 9,200 / 15,233 | 14,690 / 20,846 | 25 |

Реальная карта: 35 295 провинций, 92 452 неориентированных ребра.
В двух отдельных сериях среда/нагрузка могут отличаться; это не прямое
соревнование Odin с Rust. Главное: ни один не выиграл медиану у своего C#
baseline. Более низкий отдельный p95 не доказывает ускорение всей игры.
Счётчик managed allocations не измеряет native runtime startup/память.

**Игровой hook снят, Corridors не переведён на native.** Исходники остались
только в Tools, игра не требует этих DLL. На Nim тот же BFS пока не дублируем:
это не решает цену границы и материализации.

## F#: чистые правила, а не перенос кампании

В Tools добавлена библиотека net8.0 с правилом готовности к атаке:
только bool/int32/float32 → неизменяемая оценка, без Godot/мира/RNG.
Порядок отказов, прямой приказ, равенство порогу, нулевой отключённый порог,
NaN/Infinity, signed zero и насыщаемое вычитание дней совпадают с C#.

Стенд компилирует фактический AssaultReadiness/BattleReadout из игры, а не
копию эталона: **624 502 случая, 0 расхождений, exit 0**; ещё 4096 повторений
каждого assessor не меняют fingerprint, армию, часы, пороги или RNG.
Независимое повторение и обзор подтвердили результат.
[Код, команда и состав матрицы](../Tools/GodotLanguages/experiments/assault-rules/README.md).

Игра net10, общие тестовые хосты net8; потому библиотека на net8, а не
несовместимая ссылка на net10-only шаблон. FSharp.Core находится лишь в ignored
выходе эксперимента. Перед будущим подключением нужны deployment/export-проверка,
поставляемая managed-зависимость и оценка удобства сопровождения. Автоматическое
ускорение F# против C# не заявлено.

## Luau и Nim: следующие осмысленные задачи

Luau — опциональные формулы на копии данных и небольшой capability API.
JSON scripted_modifiers уже покрывает base/add/factor/trigger, поэтому язык нужен
для формул, которым действительно тесно в данных, а не вместо простых модов.
Полный executor событий/решений ещё не экспортирован игровым ModApi.
Старые прямые setter-операции нельзя объявлять queued/sandboxed; .lua игрового
хоста и .luau нового комплекта требуют отдельной миграции.

Nim — отдельный validator/converter для авторов карт и региональных данных
с общими fixtures существующего парсера: диагностировать province ID, owner/
controller, point rows и комментарии до запуска игры. Это кандидат, **не готовая
новая функция**. Нельзя обещать полный Godot4.8 API по старому generated каталогу.

Odin сохраняет высокий приоритет для плотных raster/overlay/preprocessing задач,
если профиль покажет узкое место. Следующий перенос выбирается по фактам,
не по количеству языков.

## Проверки этого среза

- Игра и основной стенд в публикуемой копии: 0 ошибок/0 предупреждений;
  полный FormableTests **2855 PASS**, exit 0.
- Ownership suite: 30 managed; 31 с реальным Odin. Rust и отказные DLL
  дополнительно проверяются отдельными командами, не требуются обычному стенду.
- Rust release unit tests: 7/7. Odin прямой ABI: 22 случая.
- Общий host: четыре упорядоченных fixture + 300 случайных графов; Rust smoke
  3653 проверки, Odin self-test+реальная карта 3934, синтетика 303, exit 0.
- ABI2, status3 с испорченным scratch и malformed-success fixtures: 11 проверок
  полного fallback; это специальные тестовые DLL, не игровой backend.
- Godot4.8 Beta1 headless verification: EXPORT_VERIFY failures=0, exit 0.
  Визуал/UI не менялся; новых скриншотов этот срез не требует.
- Исправлен Tools/dev.ps1: тесты инкрементально пересобираются, а не используют
  stale --no-build assembly, которая могла проигнорировать новый suite flag.
  Default путь обновлён на Beta1.

Во временном прототипе игровой native-hook прошёл 30 дней и snapshot continuation,
но после отрицательного замера был снят. Первое расхождение продолжения оказалось
ошибкой стенда: клону topology не вернули hydrology/lake data. После восстановления
того же ввода C#/native дали 31 одинаковую дневную запись. SaveSystem не менялся;
ошибка самой игры этим не доказана.

Общий SimBench 365 на публикуемом снимке завершился с шестью красными контрактами:
allocations 349 kB против бюджета 300 kB, различия shipped define defaults,
расхождение peer-GDP в проверке отделения, два отсутствующих sprite alias,
годовой фронт UKR 72% и отсутствие ожидаемого падения торговли после embargo.
Ownership native-hook там выключен. Этот результат не маскируется зелёными
узкими тестами и не используется для объявления всей симуляции готовой.
Все сетевые replay/export/platform проверки и миграция
боевых правил в игру не объявлены пройденными этим отчётом. Бинарники, compiler
caches и игровые билды не публикуются.
