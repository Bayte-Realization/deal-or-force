# Возвращение флагов движений — 16 октября 2026

На снимке пользователя видны процедурные солнца/горы вместо узнаваемых знамён.
Проверка наличия PNG не ловила это: файл существовал, но картинка была не той.

Причина двойная. Новые flag_<tag> вытесняли уже существующие культурные знамёна,
которые движения раньше получали через fallback. Синтетические политические
варианты дополнительно опережали собственные флаги организаций. Отдельная
настройка movement_flags скрывала authored insignia по умолчанию.

Возвращены 20 региональных изображений из уже поставляемой библиотеки:
Бавария, Шотландия, Уэльс, Квебек, Каталония, Крымские татары и другие.
Источник каждого PNG записан в Tools/IconCompiler/Source/movement-banners.json.
Это региональные/культурные знамёна, не заявление, что каждое из них является
официальным логотипом конкретной партии. Новых изображений и платных генераций нет.

Безземельная организация теперь предпочитает собственный flag_<tag>, а не
процедурный вариант её гипотетического правительства. При появлении территории
или провозглашении формабла обычные динамические правила остаются.
Мод может явно выбрать прежний режим через common/flags:
`{ "prefer_movement_base": false }`.
Ключ кэша интерфейса теперь учитывает Landless и Exile.

Собственные insignia включены по умолчанию; ручное выключение остаётся.
Существующая явно сохранённая настройка игрока не перезаписывается.
Генератор больше не создаёт политические заглушки движений; при отсутствии
защищённого базового PNG возвращает его из указанного источника.
Произвольные будущие движения без artwork всё ещё могут использовать fallback.

373 focused flag checks: PASS в публикационной копии.
Проверяются выбор изображения, отсутствие подмены политическими вариантами,
динамические правительства/формаблы, настройка мода и точные байты 20 источников.
Последний полный стенд до добавления 20 checksum-проверок: 3623 PASS.
