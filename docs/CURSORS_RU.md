# Курсоры игры

Курсор — аппаратный указатель Godot, не нарисованный каждый кадр элемент UI. Его
нет на снимке viewport: для оценки рисунка используется отдельный просмотр SVG,
для проверки в игре — установка палитры и запрашиваемая контролом форма курсора.

Палитра установлена для всех 17 состояний Godot. `GameCursorService` живёт над
сценами: отдельное главное меню, кампания и редакторы пользуются одной службой.
Выход из кампании больше не сбрасывает указатель на системный. Изменение каталогов
спрайтов и интерфейса обновляет палитру без постоянного создания текстур.

## Замена в моде

Поместите свои SVG/PNG в `gfx/interface/cursors` мода. Имена спрайтов:

```
cursor_arrow       cursor_ibeam        cursor_hand        cursor_cross
cursor_wait        cursor_busy         cursor_drag        cursor_can_drop
cursor_forbidden   cursor_vsize        cursor_hsize       cursor_bdiagsize
cursor_fdiagsize   cursor_move         cursor_vsplit      cursor_hsplit
cursor_help
```

В базе drag использует move, vsplit — vsize, hsplit — hsize. Это только значения
по умолчанию: мод может предоставить отдельное изображение для каждого состояния.
Файлы могут загружаться из внешнего мода без предварительного импорта Godot.

Настройки размещаются в JSON внутри `gui` мода. Например:

```json
{
  "metrics": {
    "cursor.enabled": 1,
    "cursor.scale": 1,
    "cursor.arrow.hotspot_x": 2,
    "cursor.arrow.hotspot_y": 2
  }
}
```

Hotspot задаётся в пикселях исходного изображения. Это точка клика, а не смещение
всего курсора. Для базы arrow/busy/can_drop/help — (2,2), hand — (10,3), остальные —
(16,16). Все базовые изображения имеют холст 32×32; стрелка компактнее его границ.

`cursor.scale` допускает 0.75–2. SVG заново растеризуется в конечном размере, а не
растягивается из маленького bitmap. Для растровых файлов применяется Lanczos.
`cursor.enabled: 0` возвращает системные указатели. Неверное изображение или hotspot
даёт предупреждение и базовый fallback; повреждённый базовый ресурс — системный.
Изображение должно быть размером 1–256 пикселей по каждой стороне. Желательно ≤128.

## Проверки

В живом Godot проверены установка 17 форм, переключение Cross на карте / IBeam в
поиске и сохранение той же службы при возвращении из редактора в главное меню.
Просмотр базовых рисунков: `.fennara/scripts/screenshots/cursor_palette.gd`.
Регрессия редактора/переходов: `.fennara/scripts/runtime/cursor_editor_regression.gd`.
Экспорт PCK имеет запасной путь через импортированную текстуру; отдельная проверка
экспортированной игры остаётся необходимой.
