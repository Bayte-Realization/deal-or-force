# Музыка, которая читает мир

ReimAlpha, 14 октября 2026. Семь новых инструментальных записей, двухплеерный
директор с плавными переходами и отдельная региональная палитра. Задание общему
саундтреку — камерная экспериментальная электроника/лоуфай, хрупкость, асимметрия,
напряжение без героического оркестра. Региональные записи сохранены по пожеланию
автора игры, а не удалены после изменения общего направления.

## Что запускает какой контекст

| Контекст | Основание в текущей симуляции |
| --- | --- |
| Спокойствие | Нет острой угрозы, меню всегда спокойно. |
| Неспокойный мир | Низкая стабильность, дефицит, противостояние, радикализм выбранного своего региона или широкая война за рубежом. |
| Острый кризис | Активная институциональная угроза, дефолт, тяжёлый дефицит либо очень широкое вовлечение населения мира в войны. |
| Война | Своя страна участвует в незавершённой войне. |
| После бури | Своя страна недавно вышла из войны; по умолчанию 180 игровых дней. |
| Мироустройство под угрозой | Одновременно воюют хотя бы 10 стран, охватывающие ≥60% мирового населения и ≥55% ВВП; либо сценарий явно устанавливает сигнал `world_order_emergency`. |

Последний контекст имеет приоритет над обычной войной. Самостоятельной модели
ядерных арсеналов, готовности и пуска эта работа НЕ добавляет. Сигнал для неё
подготовлен, но флаг не выдумывает ядерный кризис и не включается автоматически
из-за отсутствия ключа в старом сценарии.

Наблюдатель читает мировой контекст; выбранный регион задаёт региональную палитру,
не притворяясь страной игрока. Для игрока палитра берётся из континента страны.
Азия допускает и региональные, и универсальные композиции.

Резкое усиление требует устойчивого сигнала (6 секунд и минимальное удержание),
ослабление — 35 секунд и удержание 45 секунд. Это реальное время представления:
игровая пауза не замораживает проигрыватель. Мод может изменить эти значения.
Переход занимает 7 секунд с равномощностными кривыми; совместимый трек не
перезапускается из-за обновления числа. Громкость/отключение применяются и во время
перехода. Музыкальный выбор не расходует генератор случайных чисел кампании.

Это сгенерированные материалы: «человеческий/любительский характер» — художественный
бриф, не заявление о человеческом исполнителе. Автоматические проверки подтверждают
декодирование, уровни и работу цикла, но не заменяют прослушивание автором игры.
Старые четыре записи остаются на диске; новые каталоги только исключают их из
активного выбора. Исходные MP3 и промежуточные файлы сохранены вне доставки.

## Бесконечно восходящий цикл

`Last lap of the world` — нервная последняя прямая, подвижная и немного ироничная,
но печальная. В сгенерированную основу добавлен воспроизводимый слой Шепарда/Риссе:
октавные голоса растут, верхние незаметно затихают, нижние входят. Принцип описан
в [материале Exploratorium о непрерывных тонах](https://annex.exploratorium.edu/exhibits/highest_note/fr.continuous.html).
Это иллюзия продолжения роста, не бесконечное увеличение громкости.

На границе основы сделан однобарный переход (128 BPM, 1.875 с). Собственный слой
имеет согласованные интегральные фазы. Итог декодируется в 58.125 с PCM; контейнер
Vorbis сообщает 58.2 с из-за кодерного заполнения. В Godot проверен реальный переход
через конец записи с сохранением `Playing` и `AudioStreamOggVorbis.Loop`.
Рецепт находится в `Tools/AudioCompiler`; загруженный исходник CreativeClaw — ещё
не этот обработанный игровой файл.

## Моддинг без переписывания проигрывателя

Файлы `music/*.json` (также YAML через общий загрузчик) накладываются в порядке
пакетов. Пути относительны корню `music` данного пакета. Пример:

```json
{
  "director": { "fade_seconds": 9, "release_seconds": 50 },
  "tracks": {
    "frayed_civic": "audio/my_civic.ogg",
    "my_pressure": {
      "file": "audio/my_pressure.ogg", "when": "campaign",
      "moods": ["uneasy", "crisis"], "regions": ["europe"],
      "weight": 2, "volume_db": -2, "loop": false
    },
    "soft_fracture": { "remove": true }
  }
}
```

Замена одним путём сохраняет прежние теги, регион, уровень и цикл. Без `moods` и
`regions` старый мод соответствует любому контексту. Намеренно пустой подходящий
список затихает, а не запускает неподходящую победную музыку. Для бесшовного повтора
используйте подготовленный Ogg/MP3 и `loop: true`; декларация сама не исправляет
стык записи. `volume_db` ограничен диапазоном −40…+6 dB.

Переключатель «Адаптивная музыка» в настройках отключает контекстный отбор,
оставляя свободный плейлист данного момента. Текущий контекст, трек и причина
видны внизу «Обстановки». Отдельные интерфейсные сигналы остаются в `sound/`.

Проверки: `dotnet run --project Tools/FormableTests -- --music-only`.
