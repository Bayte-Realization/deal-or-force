# Датированная история: 18–21 века и модовые эпохи — 18.10.2026

## Что это

Новый слой `HistoricalTimeline` читает `game/events/*.json` и
запускает событие в его дату. Событие использует тот же формат, что обычные
события: `trigger`, `options`, `effects`, `modifiers`, `declare_war_on`,
`war_goal`, `renounce_claim`. Поэтому мод может написать и революцию 1789 года,
и средневековую династическую унию, и античный союз — без правки C#.

Движок не владеет миром: он только читает дату кампании, проверяет триггер для
каждой подходящей страны и применяет выбранный эффект через существующие
команды/`ScriptedEffects`. Кампания, сохранения и сетевая авторитетность
остаются в C#.

## Формат

```json
{
  "french_revolution_1789": {
    "title": "The Bastille falls",
    "description": "…",
    "date": "1789-07-14",
    "window_days": 30,
    "trigger": { "tags": ["FRA"] },
    "ai_option": 1,
    "options": [
      { "title": "Reform the monarchy", "effects": { "stability": 0.035 } },
      { "title": "Defend the old order", "effects": { "stability": -0.075 } }
    ]
  }
}
```

- `date` — `YYYY-MM-DD`, либо `-YYYY-MM-DD` для даты до нашей эры; альтернативно
  `year`/`month`/`day` (год может быть отрицательным).
- `window_days` — сколько дней после даты событие ещё может сработать; `0` — только
  в этот день.
- `repeat_days` — повтор с той же даты (конгресс, ежегодная сессия); `0` — один раз
  на страну.
- `trigger` — обычный `ScriptedTrigger`: `tags`, `min_*`, `max_*`, `at_war`, `use`.
- `options` — обычные варианты события. Человек получает карточку; ИИ сразу берёт
  `ai_option`.
- Если вариантов нет, применяется корневой `effects`.
- `record: false` отключает строку в хронике; `chronicle` задаёт её вид.

Память о срабатывании лежит в уже сохраняемом `Nation.EventMemory` под ключом
`history:<id>`. Новых полей в сейве нет; старый сейв просто не помнит ни одного
датированного события. Кампания с `Defines.StartYear = 1789` увидит свою эпоху;
кампания 2024 года не получит события 1789 года задним числом.

## Что уже лежит в игре

`60_dated_history.json` — 15 датированных событий: год выборов 2024, Французская революция,
Венский конгресс, весна народов, Июльский кризис, русская революция, Великая
депрессия, ООН, Год Африки, нефтяной шок, падение Берлинской стены, распад СССР,
финансовый кризис 2008, пандемия 2020 и война в Украине 2022. Это **не** полная
историческая реконструкция: это проверяемый набор, на котором движок и моды могут
строить свои эпохи.

Условия, которые нельзя выразить числом (смена правительства, создание
государства, вступление в организацию), пока делаются существующими командами и
мод-хуками; сам timeline не подменяет внешнюю политику и не создаёт страны из
даты.
