# Deal or Force — PortAlpha 0.8.8.6

27 November 2026 · Windows x64 & Android · Godot 4.8 Beta 3 (.NET 10)

PortAlpha 0.8.8.6 advances the **PortAlpha** publication branch (Android `versionCode` 15) with a 5-pillar real-time map sync, GPU compute, zero-`SubViewport` battle instancing, anti-burst time pacing, and native Rust SIMD / GC architecture upgrade that eliminates real-time map lag behind the in-game clock, smooths jerky Speed 1–5 time progression, slashes VRAM and managed GC pressure, and accelerates both PC and Android simulation while preserving 100% bit-exact `CampaignFingerprint` determinism (`453874FF571A1F55`). For earlier notes see [CHANGELOG 0.8.8.2](CHANGELOG_0.8.8.2_EN.md) and [CHANGELOG 0.8.7.3](CHANGELOG_0.8.7.3_EN.md).

---

## Pillar 1 — Lock-Free Triple-Buffered `WorldVisualSnapshot` & Frame-0 Clock/Map Lockstep

- **Wait-free SPSC triple buffer (`Scripts/Simulation/WorldVisualSnapshot.cs`).** Decouples `DoF-Sim` from `GlobePresentation` rendering locks using `LockFreeTripleBuffer<WorldVisualState>` (100% Godot-free simulation code, 0 static mutable fields). Captures synchronized `Date`, `ElapsedDays`/`ElapsedHours`, `MapRevision`/`OwnershipRevision`/`WarRevision`, province controllers/owners, leases, live war belligerents, and battle readouts atomically on completed step boundaries.
- **Lock-free Frame-0 globe synchronization (`Scripts/gfx/GlobeLockFreeSync.cs`, `Scripts/DealOrForceGame.cs`).** Updates province controllers, live war fronts (`PaintLiveWarFrontsLockFree`), GPU battle badges (`SyncBattleMarkersLockFree`, honoring Fog of War), country labels (`RefreshCountryLabelPlacementLockFree`), and map plates from the latest published snapshot without stalling on `CampaignAccessGate`.
- **Atomic clock/map publication & soft render backpressure (`Scripts/Simulation/BackgroundSimRunner.cs`).** Removed premature mid-batch `PublishCompletedDate` leaps, guaranteed Speed-5 batch exits at clean completed step boundaries once the snapshot cadence elapses (`14 ms` desktop / `24 ms` mobile), and added bounded render backpressure (`NotifyVisualFramePresented`, active only when a live renderer reports frames, zero overhead in headless/tests).

## Pillar 2 — Forward+ GLSL 450 GPU Compute Shaders (`1+JFA`) & Incremental Dirty-Rect Mipmaps

- **Zero-copy Vulkan/D3D12 compute pipeline (`Scripts/gfx/GpuMapCompute.cs`, `Scripts/gfx/GlobePlateRepaint.cs`).** On Forward+ (`RenderingServer.GetRenderingDevice() != null`), runs `PoliticalPlate` shading and 6-pass `1+JFA` (`1, 16, 8, 4, 2, 1`) `FrontierField` distance baking directly inside GPU VRAM using `DataFormat.R32Uint` storage images (with antimeridian wrap `dx = min(dx, w - dx)`), binding directly to `Texture2Drd` without RAM→VRAM stalls, with async `CallOnRenderThread` initialization and clean automatic fallback to CPU incremental Rust/C# on Compatibility/GLES3 or headless.
- **Incremental dirty-rect `PoliticalPlate` & `FrontierField` + incremental mipmap pyramid (`Scripts/Simulation/ProvinceRasterBounds.cs`, `PoliticalPlate.cs`, `FrontierField.cs`, `native/dof_kernels/src/raster_incremental.rs`).** Repaints only changed warfront bounding boxes and updates only affected mipmap pyramid sub-rects directly in Rust SIMD or bit-exact C#, eliminating full-planet `Image.GenerateMipmaps()` stalls on Android and GLES3 (`plate_dirty_rect+mip (128×128)`: **`22.83×`** vs Rust full-planet / **`83×`** vs C# full-planet; `frontier_dirty_rect+mip`: **`8.69×`**, 100% bit-exact across every mip level). Repaint cadences tightened to `0.16 s` GPU / `0.25–0.35 s` CPU desktop / `1.0 s` mobile.

## Pillar 3 — Zero-`SubViewport` GPU-Instanced Battle Badges & Unmanaged `Image` Leak Closure

- **Analytical SDF `BattleBadgeGpu` (`Scripts/gfx/SurfaceBattleBadge.cs`, `Scripts/gfx/MilitaryPresentation.cs`).** Replaced per-battle `128×128` `SubViewport` FBOs with a single `MultiMeshInstance3D` draw call using an analytical SDF medallion shader, 15-bit packed defender RGB, `Ui.Colour` tokens, and an 18 KB `384×48` R8 digit atlas (`-1.5–2.25 GB` peak VRAM, `-960` scene-tree nodes, zero `SubViewport` allocations).
- **Unmanaged `Image` disposal fixes.** Closed undisposed temporary `Image` handles across `GlobePackedTextures`, `GlobeMovements`, `GlobeCities`, and `GlobePresentation.FleetsAndCapitals`.

## Pillar 4 — Smooth Anti-Burst Time Pacing & Verbose Log Gating

- **Anti-burst Speed 1–4 accumulator pacing (`BackgroundSimRunner.cs`).** Clamps wake `dt` to `80 ms`, caps Speed 1–3 accumulators at `1.15×` and Speed 4 at `1.6×` (max 2 steps/batch), and applies soft decay (`min(acc * 0.25, stepInterval * 0.35)`) after heavy ticks instead of hard-zeroing — eliminating pause-then-jump bursts.
- **High-volume `simulation.log` gating (`DiagnosticLogs.cs`, `Campaign.TickStages.cs`, `CombatCore.cs`, `LongRangeMovement.cs`).** Gates `DAY_BEGIN`, `DAY_END`, `BATTLE_ROUND`, and `SUPPORT_RELOCATE` behind `DiagnosticLogs.VerboseSimulation` (off by default; opt-in via `"verbose_simulation": true` in `00_logging.json` or `DOF_VERBOSE_SIM_LOG=1`).
