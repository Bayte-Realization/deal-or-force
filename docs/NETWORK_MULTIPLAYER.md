# Сетевой мультиплеер

## Быстрый запуск

1. У всех игроков должна быть одна версия игры и одинаковый набор модов.
2. Хост открывает `Multiplayer · LAN / IP`, выбирает тег страны, оставляет UDP-порт `7270` и нажимает `HOST`.
3. Остальные игроки вводят имя, уникальный тег страны, IPv4 хоста и тот же порт, затем нажимают `JOIN`.
4. После регистрации минимум двух игроков хост нажимает `START CAMPAIGN`.

В обычной LAN используется локальный IPv4 хоста. В Radmin VPN или Hamachi используется IPv4, показанный виртуальной сетью. Для прямого подключения через интернет без VPN маршрутизатор хоста должен пересылать UDP `7270` на его компьютер. Windows Firewall также должен разрешать входящий UDP для игры.

## Модель синхронизации

Хост является единственным авторитетом:

- клиент отправляет только сериализованную `ICampaignCommand`;
- хост сверяет `IssuerId` с назначенной игроку страной и отклоняет подмену;
- принятая команда надёжно рассылается всем участникам;
- ход календаря, пауза и скорость принадлежат хосту;
- стартовый и поздний вход получают сжатый snapshot кампании;
- страны подключённых игроков помечаются human seat и не управляются AI.

Симуляция остаётся детерминированной: клиенты повторяют подтверждённые команды и тики, а интерфейс не передаёт Godot-узлы или экранные координаты. Поэтому Radmin нужен только как удобная IP-сеть — игра не симулирует «двух игроков за одной клавиатурой».

## Ограничения текущего этапа

- потеря хоста завершает сессию: миграции хоста пока нет;
- автоматическое сравнение checksum и фоновый resync ещё предстоит добавить;
- NAT traversal/relay и публичный браузер серверов не реализованы;
- перед большой кампанией рекомендуется короткий тест соединения и проверка одинакового mod fingerprint.

## Связанные файлы

- `Scripts/NetworkMultiplayerUI.cs` — лобби, ENet, RPC, выдача стран и авторитетный календарь;
- `Scripts/Simulation/NetworkCommandCodec.cs` — белый список и сериализация команд;
- `Scripts/Simulation/SaveSystem.cs` — snapshot для подключения;
- `Scripts/Simulation/SimulationCore.cs` — перехват очереди команд клиентом.
