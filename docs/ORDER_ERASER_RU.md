# Удаление приказов на карте

## Два разных действия

- **Очистить планы** удаляет целиком принадлежащие игроку планы, связанные с выделенными дивизиями. Другие участники этих планов тоже прекращают плановое движение. Несвязанные планы не затрагиваются.
- **Ластик** включает отдельный режим карты. ЛКМ по линии наступления/стрелке удаляет наступательную цель, сохраняя исходный фронт. ЛКМ по исходному фронту удаляет весь этот план. Для оборонительного рубежа удаляется его план. Esc или повторное нажатие выключает ластик; вращение/перемещение камеры и масштабирование остаются доступны.

Удаление очищает маршруты и исполнение приказа, но не перемещает дивизии и не отменяет уже идущую битву. Для этого есть отдельная команда **Выйти из боя**.

## Почему старое «Стереть» оставляло линии

Оно снимало только выделенные дивизии с плана. Невыделенные участники могли сохранять линию, а маршруты выделенных не обязательно останавливались. Теперь проверяются как сохранённые списки участников, так и актуальные `Army.FrontLineId`: погибшие, переведённые и отсутствующие в старом списке дивизии не мешают удалению.

При попадании в стрелки используется геометрия реально нарисованных лент, допуск 14 экранных пикселей. Фронт и закрашенная область, рисуемые шейдером провинций, выбираются по провинции. Если несколько таких планов совпадают, выбирается первый по стабильному ID. Выбор перекрывающихся планов и подсветка под курсором пока не добавлены.
