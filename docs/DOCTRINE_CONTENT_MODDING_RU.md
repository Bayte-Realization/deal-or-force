# Добавление статей к существующей доктрине

В `common/tactical_doctrines/*.json` своего мода можно добавить только новые статьи,
не копируя всю базовую книгу. Например:

```json
{
  "coast": {
    "append_nodes": [
      {
        "id": "my_mod_coast_school",
        "name": "My coastal school",
        "description": "A slower fleet with stronger supply routines.",
        "requires": ["coast_patrol"],
        "cost": 20,
        "days": 150,
        "rush_cost": 56,
        "modifiers": {"supply": 0.03, "naval_speed": -0.02}
      }
    ]
  }
}
```

Добавьте переводы имени и описания в `localization/english` и `localization/russian`.
Ключ `coast` — существующая книга, а `id` новой статьи должен быть уникален среди
всех книг и модов. Рекомендуется префикс своего мода.

`append_nodes` наследует имя, описание, вид войск, валюту и веса ИИ книги.
Старые статьи и сохранённые ID остаются прежними. `nodes` и `append_nodes` нельзя
указывать вместе; дополнение не может изменить вид войск или валюту существующей книги.
Неверная ссылка, цикл или повторный ID отклоняют дополнение целиком, а не половину графа.

Для альтернатив укажите `excludes: ["id_другого_выбора"]`. Достаточно одной стороны:
загрузчик делает запрет взаимным. Статьи, требуемые для одной специализации,
не должны одновременно требовать её исключённую альтернативу.
`ai_profiles: {"defensive": 3, "blitzkrieg": 1}` задаёт предпочтения существующего ИИ.
Это веса выбора, а не обязательное событие по таймеру или исключение для страны.

Полный пример — базовый `game/common/tactical_doctrines/60_advanced_branches.json`:
две независимые пары специализаций и по продолжению каждого пути в каждой книге.
Число статей каталога включает альтернативы: изучить одновременно обе стороны
взаимоисключающей пары нельзя. Цены, сроки и эффекты видны в той же игровой карточке.

Данные читаются в порядке загрузки. После установки/удаления дополнения перезапустите
игру; не обещается произвольное удаление уже изученных статей из старого сейва.
Устройство модов и manifest — [быстрый старт](MODDING_QUICKSTART_RU.md),
размеры окна и шрифтов — [оформление доктрин](DOCTRINE_UI_MODDING_RU.md).
