# Контекстные запасные флаги

Флаг конкретной страны или движения задавайте его собственным правилом каталога,
а не универсальным флагом идеологии. Универсальный рисунок может быть знаком
конкретной исторической страны, и его раздача всем теократиям или республикам
создаёт нелепые результаты.

В `game/common/flags/20_contextual_generics.json` флаг
`flag_ideology_theocratic_rule` ограничен тегом `VAT`: рисунок Ватикана больше
не становится запасным флагом Техрик-е Талибан Пакистан или другой теократии.
Это исправление выбора, не заявление о создании исторически точного флага ТТП.
При отсутствии подходящего собственного изображения остаётся существующий
процедурный запасной вариант.

## Модовые ограничения

`generic_flag_tags` сопоставляет имя запасного рисунка допустимым тегам.
Поздний JSON/YAML overlay заменяет список для указанного рисунка. Пустой список
снимает ограничение по тегам; остальные правила каталога продолжают действовать.

```yaml
# common/flags/90_context.yaml
generic_flag_tags:
  flag_ideology_theocratic_rule: [VAT]
```

Существующее `generic_flag_cultures` аналогично ограничивает культурный контекст.
Собственный мод может добавить отдельные рисунки и точные правила стран/движений.
Исправление запасного выбора применяется при следующем расчёте флага; оно не
переписывает пользовательский мод с явно назначенным изображением.

Тесты выбора и сохранности собственного флага Ватикана входят в `FormableTests`.
Права на сторонние рисунки описаны в [реестре происхождения](THIRD_PARTY_MEDIA.md).
