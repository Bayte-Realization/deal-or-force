# Повторное редактирование сценариев

В «Сценарии и мастерская» выберите карточку и нажмите «Редактировать выбранный сценарий».
Сценарий открывается в отдельном черновике на карте: текущая партия не заменяется.
Название, описание, дата, сид и сохранённая последовательность случайных чисел берутся
из документов сценария. При возвращении в библиотеку выбранный сценарий остаётся выделенным.

## Куда сохраняются изменения

- Документы `user://mods/editor_workspace/scenarios/<id>/scenario.json` и `world.json`
  открываются на месте. «Сохранить изменения сценария» обновляет эту пару с резервными
  копиями `.bak`; новый ID и новая карточка при каждом сохранении не создаются.
- Сценарий базовой игры или другого мода открывается как независимая копия с новым ID.
  Первое сохранение помещает её в вашу мастерскую, не меняя исходник.
- Нестандартное расположение файлов внутри мастерской также копируется, а не
  переписывается автоматически. Это защищает авторские схемы каталогов.
- Встроенный сценарий 2024 без `world.json` создаётся программно. Для него используйте
  «Редактировать текущую карту»: это снимок подготовленного мира, а не пустой документ.

Внизу редактора показано, обновляется существующий документ или создаётся копия.
Ctrl+S сохраняет сценарий. Неизменённый уже сохранённый документ закрывается без
предупреждения; новый несохранённый черновик или правки требуют подтверждения выхода.

## Сохранность и конфликты

Дополнительные поля JSON мира, сущностей и манифеста не вычищаются. Повторное
редактирование сохраняет имеющуюся историю; только создание нового снимка кампании
сбрасывает её по правилам `ExportScenarioJson`. Карта владения и список территорий
пересобираются из политического слоя. Смена даты сама по себе не создаёт данные
исторической эпохи.

Перед записью проверяются оба документа, безопасные пути, запрет ссылок/папок-ссылок,
доступность файлов и их совпадение с прочитанной версией. Если сценарий изменили другим
текстовым редактором, запись отклоняется: внешние изменения остаются на диске, ваши —
в открытом черновике. Новый черновик не может затереть существующий ID.

Файлы сначала подготавливаются отдельно. Если запись второго документа завершается
ошибкой, уже обновлённый первый и прежняя `.bak` восстанавливаются. Не закрывайте
черновик при сообщении о невозможности отката: проверьте файлы и резервные копии.
Это защита от ошибок записи внутри процесса, **не** гарантия общей атомарности двух
файлов при отключении питания или конкурентной записи точно во время публикации.

Документы сценария не являются форматом сохранения кампании. Правки этого редактора
не меняют расширения пользовательских сейвов.

## Проверки 1 октября 2026

- `Tools/FormableTests`: повторное открытие, сохранение без потери дополнительных полей,
  истории и RandomState, точные резервные копии, независимая копия внешнего сценария,
  конфликт ID, внешняя правка, read-only манифест, откат при отказе второго файла,
  отсутствие оставшихся временных файлов.
- Живой Godot Debug: создание → запись → выбор карточки → открытие → правка страны
  и модового поля → запись на месте → повторное открытие. Отдельно проверены конфликт
  внешней записи, сохранность черновика после отказа и восстановление выбора карточки.
- Интерфейс проверен при 1280×720. Применение/отмена полей нативных дочерних окон
  выполнялись сигналами кнопок; переходы библиотеки/карты и сохранение — UI-кликами.
- Первая версия тестового GDScript ошибочно превращала целочисленные поля в float
  через JSON.stringify; валидатор правильно отказал. Исправлен тест, не правила игры.

Редактор пока правит политический слой существующих провинций, не геометрию их границ.
Экспортированный PCK в этой серии не проверялся.
