# Deal or Force — PortAlpha 0.8.8.6

27 ноября 2026 · Windows x64 и Android · Godot 4.8 Beta 3 (.NET 10)

Выпуск **PortAlpha 0.8.8.6** (Android `versionCode` 15) реализует 5-компонентную перестройку синхронизации карты, GPU-вычислений, инстансинга значков боёв без `SubViewport`, плавности хода времени и нативных Rust SIMD / GC-оптимизаций: устраняет отставание карты и её элементов от игрового времени, убирает рывки хода времени на скоростях 1–5, резко сокращает VRAM/RAM и давление GC на ПК и Android при полном сохранении побитово-точного детерминизма `CampaignFingerprint` (`453874FF571A1F55`). Предыдущие выпуски описаны в [CHANGELOG 0.8.8.2](CHANGELOG_0.8.8.2_RU.md) и [CHANGELOG 0.8.7.3](CHANGELOG_0.8.7.3_RU.md).

---

## Компонент 1 — Lock-Free тройная буферизация `WorldVisualSnapshot` и Frame-0 синхронизация карты и часов

- **Wait-free SPSC тройной буфер (`Scripts/Simulation/WorldVisualSnapshot.cs`).** Полностью развязывает поток симуляции `DoF-Sim` и рендер `GlobePresentation` через `LockFreeTripleBuffer<WorldVisualState>` (0 типов Godot в симуляции, 0 статических мутабельных полей). Атомарно захватывает дату, `ElapsedDays`/`ElapsedHours`, ревизии карты/владения/войн, контроллеры провинций, аренды, участников войн и сводки боёв на чистой границе завершённого шага.
- **Lock-free Frame-0 синхронизация глобуса (`Scripts/gfx/GlobeLockFreeSync.cs`, `Scripts/DealOrForceGame.cs`).** Обновляет контроллеры провинций, живые фронты (`PaintLiveWarFrontsLockFree`), GPU-значки боёв (`SyncBattleMarkersLockFree` с учётом тумана войны), подписи стран (`RefreshCountryLabelPlacementLockFree`) и политическую пластину напрямую из последнего снимка без ожидания замка `CampaignAccessGate`.
- **Атомарная публикация часов/карты и мягкий backpressure рендера (`Scripts/Simulation/BackgroundSimRunner.cs`).** Убраны преждевременные скачки `PublishCompletedDate` внутри пакета шагов, гарантирован выход из Speed-5 пакета на чистой границе шага по истечении окна публикации (`14 мс` ПК / `24 мс` Android) и добавлен ограниченный backpressure (`NotifyVisualFramePresented`, активный только при живом рендере, 0 оверхеда в тестах/SimBench).

## Компонент 2 — Вычислительные шейдеры GLSL 450 (`1+JFA`) и инкрементальные dirty-rect мипмапы

- **Zero-copy Vulkan/D3D12 compute-конвейер (`Scripts/gfx/GpuMapCompute.cs`, `Scripts/gfx/GlobePlateRepaint.cs`).** На Forward+ (`RenderingServer.GetRenderingDevice() != null`) переносит раскраску `PoliticalPlate` и 6-проходный `1+JFA` (`1, 16, 8, 4, 2, 1`) расчёт `FrontierField` прямо в VRAM на `DataFormat.R32Uint` storage-текстурах (со сшивкой по антимеридиану `dx = min(dx, w - dx)`), подключая результат напрямую через `Texture2Drd` без перегонки RAM→VRAM; инициализация идёт асинхронно через `CallOnRenderThread` с чистым откатом на CPU-фолбэк на Compatibility/GLES3 и в headless.
- **Инкрементальные dirty-rect `PoliticalPlate` и `FrontierField` + частичные мипмапы (`Scripts/Simulation/ProvinceRasterBounds.cs`, `PoliticalPlate.cs`, `FrontierField.cs`, `native/dof_kernels/src/raster_incremental.rs`).** Перерисовывает только изменившиеся прямоугольники фронта и обновляет только затронутые узлы пирамиды мипмапов на Rust SIMD или побитово-точном C#, убирая фризы полного `Image.GenerateMipmaps()` на Android и GLES3 (`plate_dirty_rect+mip (128×128)`: **`22.83×`** против полного Rust / **`83×`** против полного C#; `frontier_dirty_rect+mip`: **`8.69×`**, побитово-точно по всем уровням мипов). Каденс перекраски ускорен до `0.16 с` на GPU / `0.25–0.35 с` на CPU ПК / `1.0 с` на мобильных.

## Компонент 3 — GPU-инстансинг значков боёв без `SubViewport` и закрытие утечек `Image`

- **Аналитический SDF `BattleBadgeGpu` (`Scripts/gfx/SurfaceBattleBadge.cs`, `Scripts/gfx/MilitaryPresentation.cs`).** Отдельные `128×128` `SubViewport` FBO заменены на один `MultiMeshInstance3D` draw call с аналитическим SDF-шейдером медальона, 15-битной упаковкой цвета защитника, токенами `Ui.Colour` и 18 КБ атласом цифр `384×48` R8 (`-1.5–2.25 ГБ` пиковой VRAM, `-960` узлов сцены, 0 `SubViewport`).
- **Закрытие утечек неуправляемых `Image`.** Добавлен `using`/`.Dispose()` для временных `Image` в `GlobePackedTextures`, `GlobeMovements`, `GlobeCities` и `GlobePresentation.FleetsAndCapitals`.

## Компонент 4 — Анти-рывковый темп времени и отключение спама `simulation.log`

- **Плавный аккумулятор скоростей 1–4 (`BackgroundSimRunner.cs`).** Ограничен всплеск `dt` пробуждения до `80 мс`, потолок аккумулятора сужен до `1.15×` на скоростях 1–3 и `1.6×` (не более 2 шагов за пакет) на скорости 4, а после тяжёлого шага вместо жёсткого обнуления применяется мягкое затухание (`min(acc * 0.25, stepInterval * 0.35)`).
- **Управление подробным `simulation.log` (`DiagnosticLogs.cs`, `Campaign.TickStages.cs`, `CombatCore.cs`, `LongRangeMovement.cs`).** Высокочастотные строки `DAY_BEGIN`, `DAY_END`, `BATTLE_ROUND` и `SUPPORT_RELOCATE` вынесены под флаг `DiagnosticLogs.VerboseSimulation` (выключен по умолчанию; включается через `"verbose_simulation": true` в `00_logging.json` или `DOF_VERBOSE_SIM_LOG=1`).

## Компонент 5 — Расширенные Rust SIMD-ядра (`Caps=0x3DF`) и ускорение симуляции / Android MonoVM

- **17/17 BIT-EXACT нативных Rust SIMD-ядер (`native/dof_kernels/`, Win64 AVX2 + Android `arm64-v8a` NEON + `x86_64`).** Добавлены флаги `CapIncrementalRaster` (`256`) и `CapWartimeGraph` (`512`): `graph_occupation` **`28.15×`**, `plate_dirty_rect+mip` **`23.20×`** (`86×` против C# всей планеты), `econ_vital_rates` **`15.91×`**, `frontier_dirty_rect+mip` **`8.94×`**, `demo_step_cohorts` **`6.63×`**, `political_plate` **`6.11×`**, `econ_household_groups` **`6.00×`**, `dip_pair_score` **`5.30×`**, `demo_aggregate_nations` **`4.21×`**, `graph_vision_seed` **`4.00×`**, `market_settle` **`3.81×`**, `political_cohorts` **`2.13×`**.
- **Разблокировка production-ядер и инвалидация CSR-графа.** Исправлен `DemographyRulesHook.IsCustomInstalled`, чтобы `DemographyRulesFSharpBoot` больше не отключал `econ_vital_rates` (`15.9×`) и `demo_step_cohorts` (`6.6×`) в живой игре на ПК и Android; `NativeProvinceGraph.ForMap` теперь отслеживает `ProvinceTopology.AdjacencyRevision` при подключении переправ.
- **Снижение CPU и MonoVM GC в C#.** Добавлены `TerritorialDisputeIndex` (O(1) отсев 99.7% пар без споров в `OpinionCore.StandingClaimAndCycle`), кэш сигнатуры обзора в `ProvinceVision.FastPath.cs` (GC `intel.visibility` `-46%`), не-боксирующий `StrategicWar.EnemiesOf` (`SideEnumerable` + `Contains` для 45+ точек вызова), переиспользуемый `CoalesceScratch` в `DemographicCycle` (убраны `HeapSpanDictionary` на каждый регион), разделение `PeacefulFormationCache` по `RegionLayoutRevision`, кэш веры в `StateIdentity`, zero-alloc `StrategicChokepoints.IsCommoditySqueezed` и пакетирование `CombatCore.ResolveAdvancesStages`.
- **Замеры `SimBench` и гигиена архитектуры.** `SimBench 365d --soak --wars`: **`Soak PASS` (365/365 дней, 0 алертов)**, скорость на 365-й день **`18.83 дн/с` (`53.1 мс/день`, `+55%` к `12.12 дн/с` в `0.8.8.2`)** при `1 700 КБ/день`. `SimBench 120d --profile`: суммарное CPU процесса **`185.7 → 151.6 мс/день` (`-18.4%`)**, стена `95.15 мс/день`, медиана плавного кадра **`1.37 → 1.17 мс` (`-14.6%`, `0` кадров `>33 мс`)**, GC `intel.visibility` **`7.6 → 4.1 МБ` (`-46%`)**, GC `war:advances` **`14.0 → 10.5 МБ` (`-25%`)**, `godotInSim=0`, `maxFileLines 3308 → 3281`, `simStaticMutable 1408 → 1405`, `deadCandidates 170 → 169`, `31 656` PASS / `0` FAIL в `FormableTests` и побитово-точный 183-дневный отпечаток (`453874FF571A1F55`) между Rust SIMD и `DOF_KERNELS_DISABLE=1`.
