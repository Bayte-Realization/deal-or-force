# Ультиматумы: пакет требований и защищённый мир

В дипломатии и карточке страны кнопка «Предъявить ультиматум» открывает отдельное окно. Выбор региона на карте больше не обязателен.

Условия можно комбинировать:

- Несколько регионов с поиском и независимыми отметками.
- Разовая выплата из казны адресата.
- Снятие его эмбарго против вашей страны (если такое эмбарго существует).
- Пакт о ненападении.

Окно показывает фактическую оценку ответа ИИ, долю населения в территориальных требованиях, соотношение сил и полный список условий. Это оценка текущего состояния, не случайная «вероятность успеха». Больший пакет повышает порог согласия. Перед отправкой требуется отдельное подтверждение; изменение условий снимает подтверждение. После отправки условия блокируются, результат остаётся видимым. Escape закрывает окно.

## Мир и отказ

При согласии пакет применяется целиком и устанавливается двустороннее перемирие на **180 дней**. При отказе **ничего не передаётся**: появляется повод для войны, но объявить её можно только через **3 дня**. Все объявления войны проходят одну проверку, включая команды, ИИ и повторное воспроизведение. Перемирие сохраняется в сохранениях и сетевых снимках.

Нельзя требовать всю оставшуюся территорию страны, регион с чужими или оккупированными провинциями, чужой регион или недопустимую выплату. Весь пакет проверяется до первой уступки. Государство, утратившее всю землю, не может стать целью территориальной войны.

Пакт о ненападении — отдельное соглашение: его действие не заканчивается автоматически вместе с перемирием. Для новой войны нужно сначала прекратить пакт обычным дипломатическим действием. Автоматический ответ за другого человека не реализован: ультиматумы человеческим игрокам явно недоступны, их решение не подменяется ИИ.

## Моддинг

`game/common/defines/47_ultimatums.json`:

```json
{
  "UltimatumMaxRegions": 8,
  "UltimatumMaxTreasuryShare": 0.5,
  "UltimatumSettlementTruceDays": 180,
  "UltimatumRefusalTruceDays": 3
}
```

Денежные суммы в командах — миллиарды долларов. Длительность защищённой паузы не может быть меньше одного дня даже при нулевом дефайне. В командном пакете `IssueUltimatumCommand` используются `StateMapIndices`, `Reparations`, `LiftEmbargo`, `NonAggression`; старое поле `StateMapIndex` сохранено для совместимости. Расположение окна — `game/gui/40_ultimatums.json`, русские строки — `game/localization/russian/135_ultimatum_composer.json`.

Проверка ядра: `dotnet run --project Tools/FormableTests -- --ultimatum-only`. Набор покрывает многорегионные соглашения, отказ, денежный баланс, эмбарго, пакт, сохранения, сетевые команды, паузу и запрет «войн с воздухом».
