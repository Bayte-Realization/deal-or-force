# Мирные объединения и моддинг

Мирный путь дополняет территориальные условия формируемого государства. Приглашение не меняет границы: сначала партнёр подписывает ограниченное по времени согласие, затем основатель выполняет весь список условий и подтверждает провозглашение.

## Данные

- `game/common/formable_nations/20_peaceful_paths.json`: включает пути для конкретных государств.
- `game/common/defines/45_peaceful_unions.json`: сроки, пороги и веса оценки ИИ.
- `game/gui/33_formable_nations.json`: размеры флагов, поиска, карточек и кнопок.
- `game/gui/34_support_map.json`: цвета типов дальнобойных частей и их состояний, пороги видимости, расстояния между маркерами одной базы, увеличение выбранного маркера.
- `game/localization/{english,russian}/95_foundations.json`: тексты переговоров и хроники.

Создайте соответствующие файлы **в корне собственного мода**, повторив структуру каталогов `game`, а не редактируйте базовую игру. Загрузчик накладывает данные активных модов в порядке загрузки. Для нового названия объединения добавьте перевод его `name`; для нового флага используется существующее правило `gfx/flags/flag_formable_<id>.png`.

Пример частичного переопределения в `common/formable_nations/my_unions.json`:

```json
{
  "united_korea": {
    "peaceful_accession": true,
    "ai_foundation": true,
    "subject_integration": false,
    "minimum_stability": 0.75
  }
}
```

Неуказанные поля наследуются. `peaceful_accession` позволяет пригласить владельцев необходимых территорий; `subject_integration` засчитывает территории собственного лояльного субъекта. Для старых определений оба пути выключены, пока их не включает файл данных.

Внутренний редактор показывает эти поля на вкладке свойств как обычные значения JSON. Кнопки проверки и сохранения для `common/formable_nations` теперь проверяют также предметные правила: корректные переключатели, территории, диапазоны баланса и существование идеологий/форм правления. Частичный файл проверяется поверх действующего каталога, **не меняя его**. Даже проверка `disabled: true` не удаляет определение из текущей кампании. Изменения применяются при следующем запуске с активным модом.

## Ограничения и сохранность

Война, чужой сюзерен, недостаточная стабильность, оккупация необходимых провинций и отсутствие права основателя блокируют объединение. Субъект с высоким стремлением к независимости не интегрируется автоматически. В мультиплеере страны людей не поглощаются.

ИИ оценивает отношения, культурную близость, союзы, торговые соглашения, политическое сходство, лояльность и стабильность. Игрок отвечает на приглашение событием. При `ai_foundation: true` ИИ самостоятельно ведёт переговоры и позже провозглашает государство, если выполнены все условия. Неуказанное поле наследуется; у нового определения по умолчанию выключено.

### Автоматические инициативы

В `common/defines` мод может отдельно изменить:

- `UnionAiReviewDays`: интервал проверки каждой страны (90 дней); 0 выключает автоматические инициативы. Страны проверяются в разные дни, чтобы не создавать единовременную нагрузку.
- `UnionAiEarliestDay`: первые инициативы не раньше 180-го дня кампании.
- `UnionAiMinimumOwnedShare`: основатель должен владеть минимум 35% необходимых **сухопутных провинций**, не населения или ВВП.
- `UnionAiTreasuryReserveShare`: после уплаты стоимости требуется запас казны в 12% годового ВВП. Это порог решения ИИ, а не дополнительная плата.

Среди подходящих независимых стран преимущество у владеющей наибольшей долей территории; равенство разрешается по ВВП и стабильному ID. Страна игрока также участвует в выборе основателя, но ИИ ею не управляет. Оккупация, неопределённые территории сценария и война блокируют инициативу. За одну проверку основатель делает не больше одного приглашения или провозглашения. Даже мгновенный ответ ИИ не приводит к поглощению в этот же проход: для формирования нужна следующая проверка. Уже подписанные договоры с другим действующим основателем и ожидающие ответа приглашения конкурентов защищены от дублирования.

Следующая дата проверки сохраняется в `DecisionAvailableDay` страны ключом `union_ai_review`, как обычные сроки решений. Для тестового сценария можно снизить интервалы, дату старта и пороги, а конкретные пути включать/выключать независимо через `ai_foundation`. ИИ не использует случайные броски: одинаковые условия и сид дают одинаковый порядок решения.

При провозглашении передаются только территории, указанные определением и активным сценарием. Если партнёр сохранил земли за пределами объединения, он остаётся отдельной страной со своей армией. Если он присоединился полностью, сохраняются идентификаторы войск и их подготовка, флот, дальнобойные части, стройки, набор, казна, резерв людей, технологии, исследовательский прогресс и производственные назначения. Единственный игрок поглощённой страны продолжает за объединённое государство.

Согласие и ожидающее ответа событие сохраняются существующим текстовым форматом кампании; дополнительный файл для договоров не создаётся. Срок согласия не даёт вечного права на чужие земли.

## Проверки

Из корня проекта: `dotnet run --project Tools/CampaignUpgradeTests` и `dotnet run --project Tools/FormableTests`.

Первый набор проверяет продолжительность шага, договоры, истечение согласия, оккупацию, наследование активов, сохранения и событие ответа на отделение страны. Он также проверяет инициативы ИИ, право игрока отказать, отсутствие повторных приглашений, финансовый резерв, обещания другому основателю, позднее провозглашение через общий ИИ государства и изолированную проверку черновиков редактора. Второй покрывает существующие правила формирования, интерфейсные данные, редактор, сценарии, исследования и производство.
