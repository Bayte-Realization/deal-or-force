# Звук и оформление — проход 14 октября 2026

Добавлено **10 новых готовых материалов**: две инструментальные композиции,
шесть коротких звуков интерфейса и два абстрактных изображения. Они не являются
историческими картами или изображениями настоящих флагов. Происхождение и полные
задания записаны в [машиночитаемом журнале](media/atlas_20261014.json).

## Где посмотреть и послушать

В настройках кампании есть кнопка «Звук и оформление». Ещё один вход —
«Послушать и посмотреть» в ситуационной комнате. Библиотека позволяет искать,
фильтровать и вручную прослушивать материалы. Просмотр не меняет мир и не
расходует деньги. Никакое видео не запускается автоматически.

Прослушивание временно приглушает обычный саундтрек. Остановка, окончание записи
или закрытие библиотеки возвращают его. Громкость подчиняется настройкам игрока;
при выключенном звуке библиотека показывает «Звук выключен», не меняя настройку.
Клавиши времени и движения карты не проходят сквозь окно. ESC сначала снимает
фокус с поиска, затем возвращает к предыдущему экрану.

Музыку создала CreativeClaw/Lyria 3.5: запрошенные 105 секунд были ориентиром,
а не точной длительностью. Звуки — ElevenLabs Sound Effects v2, изображения —
Nano Banana 2. Применены выравнивание громкости и преобразование в локальные OGG/WAV.
Декодирование, длины и пиковые уровни проверены. Это техническая проверка, а не
гарантия художественного качества: окончательный музыкальный вкус оценивается
прослушиванием, а не названием генератора.

В библиотеке также сохранён ранее созданный «Последний круг мира». Новые
композиции не попадают в его отдельный плейлист системного кризиса. В обычном
каталоге теперь девять композиций, включая прежние региональные записи.

Сигналы событий используют существующие приоритеты и ограничения частоты.
Критическая ситуация не звучит чаще раза в 12 секунд и уступает более важным
сообщениям. Входящий документ ограничен четырьмя секундами; старые предложения
при загрузке, смене игрока или выходе из наблюдения не объявляются новыми.

## Замена в модах

Каталог находится в `game/presentation/10_atlas_library.json`. Мод может положить
свой файл в `presentation/` с таким содержимым:

```json
{
  "assets": {
    "my_recording": {
      "kind": "music",
      "name": "My recording",
      "purpose": "Quiet evening",
      "file": "music/my_recording.ogg",
      "source": "Author and applicable rights"
    }
  }
}
```

Пути разрешаются относительно пакета мода; `../`, HTTP и абсолютные пути Windows
отвергаются. Метаданные можно переопределить отдельно, не потеряв исходный путь.
`"remove": true` удаляет запись из библиотеки. При обновлении каталога открытое
окно перестраивает список.

**Библиотека не назначает музыку событиям сама.** Для автоматического воспроизведения
нужны обычные каталоги `music/` и `sound/`. Поэтому просмотр и правила игры остаются
раздельными. Видео поддерживается только как локальный OGV, вручную, без автозапуска.
Прозрачность нового заголовка задаётся `atlas.heading_opacity` в GUI-данных.

## Второй проход: управляемое прослушивание

Добавлены пауза/продолжение, перемотка и явно включаемый повтор (по умолчанию
выключен). Волна девяти записей измерена по реальной моноамплитуде, не нарисована
декоративным эквалайзером; показывается положение воспроизведения. Источник и
путь доступны по спокойной кнопке «Сведения о материале», скрыты по умолчанию.

Пауза остаётся настоящей native stream pause. Выбранная во время паузы позиция
применяется при продолжении: Godot не выполняет native seek на остановленном
голосе. Прослушивание дублирует AudioStream и выключает встроенный loop только
у копии, не портит кешированную композицию музыкального директора.

Музыка кампании и ambience карты уступают ручному прослушиванию; окончание,
Stop и закрытие возвращают оба. Тревога priority≥2 прерывает preview (порог
`media.preview_interrupt_priority` вGUIданных); маловажное уведомление — нет.
Space работает на чекбоксе повтора и не снимает паузу кампании; Home/End работают
на шкале. Кампания до/после просмотра не меняет fingerprint.

Общая очередь звуков ограничена тремя уникальными сигналами. При завершении
другого канала она больше не снимает ожидающий сигнал с очереди, пока его
собственный канал занят или более важная тревога звучит. Независимые каналы
не мешают друг другу.10regressions: занятый канал, приоритет, FIFO, границы и
отсутствующий материал; воспроизведение откладывается, не обрывает текущий звук.

Измерения находятся в `game/presentation/12_atlas_waveforms.json`:
`duration_seconds` (конечное0..86400), `peaks` (≤512конечных амплитуд0..1).
Caption-only overlay сохраняет измерения; замена `file` сбрасывает старую волну,
если новая явно не задана. Для измерения авторской музыки используйте
`Tools/MediaLibrary/MeasureWaveforms.ps1` с FFmpeg/ffprobe: он возвращает JSON
вstdout, не переписывает каталог самостоятельно.

Проверки этого слоя: **2140PASS** до присоединения новых механических блоков;
D3D12GUIv5 — **0failed checks**, 1920×1080/1280×720, раскрытие источника,
pause/seek/resume/repeat/one-shotfinish/priority. Это не новое подтверждение
векового баланса, видео или экспортированного билда.
