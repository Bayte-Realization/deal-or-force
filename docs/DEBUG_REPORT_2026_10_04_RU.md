## Общий прогон

Команда: `dotnet run --project Tools/SimBench/SimBench.csproj -c Release -- 30 20260830`.

Прогон закончен, код возврата 1, восемь замечаний. Число 30 относится к основному прогону; отдельные проверки внутри него проигрывают годы.

Три замечания разобраны и исправлены после этого прогона:

- Резервный layout `modal.ultimatum` отсутствовал в коде. Теперь совпадает с уже действующим `game/gui/40_ultimatums.json`; обычная раскладка окна не менялась.
- Проверка дефайнов сравнивала каждое промежуточное значение отдельно. Например, `OrderedAdvanceFloor` из раннего файла 0,25 уже перекрывался поздним 0,5. Теперь проверяется результат настоящего загрузчика: 437 значений совпадают. Словари проверяются по ключам и значениям, а не через `ToString()`; отрицательные пробы замечают изменённый флаг и число. Это проверка эффективных значений, не замена валидатора синтаксиса JSON.
- Проверка переводов путала ID узлов редактора с надписями. Исправлено различение двух перегрузок `ActionButton`; добавлены шесть действительно отсутствовавших ключей в обоих языках. Сейчас русский индекс покрывает 14 088 из 14 088 текстовых ключей; это полнота ключей, не художественная оценка переводов.

Повторный быстрый `--integrity-only`: пять групп PASS, код возврата 0. Полный многолетний прогон после этих исправлений повторно не запускался.

Ещё пять замечаний на момент первого разбора (обновлённый статус пункта 4 — ниже):

1. Отделение страны: в конкретной многолетней пробе одна новая страна появилась без сопротивления родителя. Нужна проверка условий сопротивления и достаточности самой пробы.
2. Переназначение целей: за трёхлетнюю пробу 3 960 смен целей против 1 918 прибытий, отношение 2,06. Приоритет для отладки ИИ и устойчивости маршрутов.
3. Исследования: за основной короткий прогон в 30 дней ни одна технология не завершена. Проверка рассчитывалась на более длинный горизонт; нельзя из этого результата заключить, что исследования сломаны, или ослабить её без отдельной проверки прогресса.
4. Построение перед наступлением: в самой загруженной провинции 3 дивизии вместо расчётной равномерной доли 2 на 8 провинций.
5. Мировое производство: недостаток фосфатов, стали, батарей, автомобилей и боеприпасов в проверяемом состоянии. Нужно разделить проблемы рецептов, ресурсов, торговли и критерий равновесия теста.

Проверки сохранения планов, морского десанта, возвращения границ из сохранения, связности мирных требований и детерминизма прошли в этом прогоне. Это не доказательство отсутствия дефектов во всех сценариях.

Профиль запускался одновременно с общим SimBench; это ориентир для поиска горячих подсистем, не измерение FPS и не честное сравнение «до/после». Особенно важны пиковые дни рынка. Массовое ускорение этим проходом не заявляется.
