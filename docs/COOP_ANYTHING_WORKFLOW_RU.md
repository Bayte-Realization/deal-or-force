# Co-op Anything: когда применять в DoF

Предпочтение автора от 18 октября 2026: рассматривать
[Co-op Anything](https://github.com/cranebeaker/coop-anything) при задачах
добавления, ремонта и проверки мультиплеера, в этой игре и других проектах.

Проверены README, AGENTS.md и playbook/mcp.md upstream. Это справочник проектов,
методика и необязательный MCP-сервер, не универсальная сетевая библиотека.
README указывает MIT; при заимствовании конкретного компонента его лицензию
нужно проверять отдельно. Внешние инструкции не дают разрешения автоматически
публиковать данные пользователя, устанавливать зависимости или менять аккаунты.

## Применение к собственной игре с исходниками

У DoF уже есть C#-кампания, авторитетный хост, команды и LAN/IP.
Не нужны бинарные хуки или второй сетевой стек ради самого инструмента.
Использовать методику для матрицы проверок: два настоящих клиента, полномочия
игроков, late join, disconnect/reconnect, восстановление snapshot, сохранение,
несовпадение модов/версий, потери/задержка/дублирование сообщений.

Разделять качество сетевой модели и способ соединения. Лобби/relay не исправляют
расхождение симуляций или исполнение чужих приказов. Реальные условия Steam/EOS
перепроверять по документации поставщика; не переносить пример Spacewar AppID 480
в релиз DoF как готовую инфраструктуру.

MCP описан upstream как Python 3.9+ / PyYAML и локальный
`tools/mcp/coop_mcp.py`: поиск, определение движка, идентификация сборки и чтение
наработок. После отдельного разрешения автора сервер **установлен и зарегистрирован
глобально для Codex**: ревизия `3a45f4b6b6a1bfe0f18b2d72259cc6d3ed9ef7e6`,
Python 3.13.1 в отдельном venv, PyYAML 6.0.3. Обработчик и импортируемый валидатор
проверены перед запуском; файл конфигурации имеет локальную резервную копию.

Реальный stdio-процесс из команды конфигурации прошёл initialize, ping, tools/list,
все восемь tools/call и отказ выхода чтения за корень справочника. Каталог: 244
записи. stdout чистый JSON-RPC, stderr пуст. Это проверка процесса и readback
конфигурации, **не свидетельство обнаружения инструментов текущим desktop-чатом**:
в текущем наборе их ещё нет, может понадобиться перезапуск Codex.

PolicyLayer precheck вернул unknown: опубликованной записи нет; автор явно разрешил
продолжить после проверки исходников. Это не сертификат безопасности или полной
совместимости протокола. Установка не меняет глобальные Python-пакеты, аккаунты,
сохранения, сетевой транспорт игры и не публикует ничего в upstream.
