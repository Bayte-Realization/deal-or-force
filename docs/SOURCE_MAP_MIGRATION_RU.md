# Переход от LegacySourceMap к модифицируемым данным

Первый этап: исходные сетки владения, административных регионов и спорных
территорий вынесены в `game/map_data/source_control.png`, `source_states.png`
и `source_disputes.png`. Все 16 588 800 значений каждого слоя перенесены без
изменений и проверены обратным чтением PNG. Эти файлы теперь используются
ванильной игрой вместо встроенных строк C#.

## Формат и моды

Это обычные lossless RGB PNG размером 5760×2880, но их цвет — числовой ID:
`ID = R + 256 × G`, синий канал всегда 0. Нулевой ID означает отсутствие
страны/региона/спора. Нельзя применять сглаживание, JPEG-сжатие, фильтры или
цветокоррекцию к этим **данным**. Размер сетки на этом этапе ещё фиксирован.

Мод кладёт нужные слои в свою папку `map_data`. Можно заменить только один слой:
остальные наследуются из ванильных данных/более ранних модов. Иные имена файлов
задаются ключами `source_control`, `source_states`, `source_disputes` в
`map_data/default.map`. Пути относительные, выход из папки запрещён.
Изменение пути, размера файла или времени изменения исходника сбрасывает старые
декодированные сетки. Повторное чтение каталога с неизменными исходниками сохраняет
уже применённые территориальные исправления и совместимость с `compiled.json`.
Некорректные размеры или
цветовая кодировка отклоняются с диагностикой, действующий слой сохраняется.

ID должны соответствовать таблицам стран и регионов. При изменении геометрии
регионов нужно согласовать её с провинциями/`definition.csv` и перекомпилировать
карту штатным компилятором. Рисование произвольных цветовых ID само по себе не
создаёт новую страну или регион. Сценарии, история и текущая ситуация сейва —
отдельные слои; PNG исходной географии не заменяют их.

## Что ещё осталось

`LegacySourceMap` пока содержит совместимый декодер, фиксированные размеры и
резервные старые упакованные таблицы для инструментов/старых установок без новых
файлов. Это промежуточный этап, не утверждение, что весь хардкод устранён.
При явной ссылке `default.map` на отсутствующий файл ванильная загрузка сообщает
об ошибке, а не незаметно подставляет старую географию. История переноса из s&box
и происхождение Natural Earth сохраняются в комментариях; резервные таблицы
можно удалять лишь после миграции всех экспортов/инструментов.

Проверка: `dotnet run --project Tools/SourceMapMigration -- --verify`.
Первичный конвертер `--export` отказывается перезаписывать существующие PNG.
