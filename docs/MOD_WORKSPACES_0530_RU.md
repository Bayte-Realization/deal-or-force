# Мастерские и замена поведения — 0.5.3.0

## Пакет выбирается явно

В общей шапке мастерской есть строка «Редактируемый мод» и действие
«Создать / выбрать мод». Оно доступно из редакторов контента, стран, флагов,
интерфейса и сценариев. Новая папка создаётся в
`Документы/Bayte Realization/Deal or Force/mods/<id>` вместе с настоящим
`manifest.json` и папками локализации EN/RU. ID — строчные латинские буквы,
цифры и `_`, начиная с буквы; системные имена Windows запрещены.

Существующую папку мастер не перезаписывает. При переключении пакета открытый
редактор перечитывает данные и контрольные версии файлов. Несохранённые изменения
требуют подтверждения; карта учитывает и собственный изменённый черновик.
Новый пакет выключен: включите его в лаунчере перед новой кампанией.
Это не загрузка непроверенного кода в текущую партию.

## Что действительно заменяется

| Изменение | Поддерживаемый способ |
| --- | --- |
| Числа, решения, события, технологии, формируемые страны | Оверлеи `common/`, `events/` с существующим ID. Не копируйте весь базовый каталог |
| Сложные повторяемые условия и последствия | `common/scripted_triggers`, `common/scripted_effects`, `use` в событиях/решениях; JSON и YAML читаются одной системой |
| Интерфейс и изображения | Каталоги `gui/`, `interface/`, `gfx/`, одинаковые ID ресурсов; редактор сохраняет в выбранный пакет |
| Поведение на C#/F# | Скомпилированная DLL, `corecode_assembly`, реализация `IGlobalityMod` |
| Отключение существующей подсистемы | Соответствующие `Features` / `FeatureSystems` в `common/defines`, только если подсистема действительно проверяет этот шлюз |
| Файл с тем же именем, что у класса игры, например `Scripts/Simulation/EconomyCore.cs` | **Не заменяет скомпилированный класс**. Такой файл сам по себе не исполняется |

Corecode — доверенный .NET-код, не песочница и не автоматически безопасный
мультиплеер. Простое совпадение namespace/имени класса в другой DLL не подменяет
класс основной сборки. Полная произвольная hot-patch-замена всех методов игры
в этом обновлении не реализована и не обещается.

Загрузчик теперь сообщает об исходниках `Scripts/*.cs`, которые не являются
заменой host-кода, и о DLL без подходящей точки входа. Порядок точек входа
фиксирован по полному имени типа. При завершении кампании выполняется `StopCode`;
собственные подписки и ресурсы мода освобождайте через `IDisposable`.

## Правила формирования и флагов

`minimum_component_share` в формируемой стране задаёт минимальную долю **каждого**
`required_tags`, а не только всей территории в сумме. По умолчанию — `0.5`;
`0` явно возвращает старую суммарную проверку. Для объединённого Китая и Великой
Италии базовая игра требует `1.0`: Тайвань, Сан-Марино, Ватикан и Мальта больше
не теряются при округлении. Динамические реставрации сохраняют отдельное правило
частичного возвращения утраченной страны. Военная оккупация не равна владению;
согласие на мирное вступление остаётся обязательным.

В `common/flags` параметр `prefer_country_base: true` сохраняет национальный флаг
при смене идеологии и правительства. Пользовательский флаг, провозглашённая страна
и реставрация сохраняют приоритет. `false` явно возвращает выбор политических
вариантов для мода, которому это нужно. Движения продолжают использовать собственные
правила знамен; уникальные китайские варианты выбираются по основателю CHN/TWN.

Подробности остальных контрактов: [руководство моддера](MODDING_GUIDE_RU.md).

Отдельная старая папка `mods/luau_events` не была подключаемым модом: в ней не
было манифеста или вызывающего её игрового кода. Справочный модуль перенесён к
шаблону: `mods/_templates/luau_engine/corecode/modules/war_damage.mod.lua`.
Удалены повторные определения функций; три итоговых предложения событий
сохранены. Перенос сам по себе не регистрирует эти события в кампании — это
объяснено в README шаблона; поддерживаемые игровые события задаются JSON/YAML.
