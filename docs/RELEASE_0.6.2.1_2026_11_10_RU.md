# EntertAlpha 0.6.2.1 — смена версии и новая сборка

## Объём прохода

По запросу автора текущая версия изменена на **0.6.2.1** во всех действующих
точках: общий MSBuild-файл, игровая константа, конфигурация Godot, Windows
file/product version, игровые и F#-сборки, лаунчер, проверка метки версии,
README EN/RU, инструкции сборки и полные ченджлоги EN/RU.
Версия новых сохранений уже связана с игровой константой. Номер формата
сохранения остаётся **2**, версия карты — `2024.11.09-a`; сетевой протокол
и игровые правила этим проходом не менялись.

Исторические отчёты, ченджлоги и готовые сборки 0.6.2.0 сохранены под их
настоящим номером. Старые пользовательские сохранения не переписывались.
Это новый экспорт из исходников, а не переименование старых EXE/PCK/DLL.

Собран исходный коммит `60df58563662dc45b32236b01434df965b088b59`,
уже отправленный в `origin/EntertAlpha`. Он указан в `BUILD_INFO.json`.
Последующий коммит этого отчёта меняет только документы приёмки, не бинарники.
Содержимое `game/` совпадает с предшествующим опубликованным срезом `dd3f7709`;
полный накопленный контент, включая последние дополнения Клода, сохранён.
