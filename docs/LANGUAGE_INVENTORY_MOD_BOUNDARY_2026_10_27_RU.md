гарантирует одинаковую скорость. Luau engine API не объявляется песочницей.

## Исправления

Числовые операции общего GDScript/Luau-моста вынесены в проверяемый C#-модуль
`ModScalarAccess`, без Godot и без новой копии состояния мира. Переносить этот
адаптер в F# ради количества языков не потребовалось.

- `set_define`: конечный double больше диапазона float раньше записывал Infinity
  и возвращал true. Теперь проверяется результат преобразования до записи.
- `set_nation_number` для населения: ввод от 2^63 раньше доходил до переполняющего
  cast в long и мог обнулить население. Теперь это отказ без изменения поля.
  `(double)long.MaxValue` уже равен 2^63; верхняя граница намеренно исключительная.
- `get_define` для текстового параметра раньше мог бросить FormatException.
  Числовой getter теперь возвращает fallback для текста/коллекций и нечисловых
  значений. Числовой setter не превращает текстовую конфигурацию в строку «12».

Сохраняются имена методов/aliases, обычные значения, прежние clamp, усечение
дробного населения, round-to-even целых define и ноль/неноль bool. Старые setter-
методы по-прежнему **немедленные**, не стали queued-командами. Очередь, multiplayer,
полномочия доверенных модов, сейвы и протокол workers не перерабатывались.
Индекс define-свойств переиспользуется вместо полного reflection-поиска на вызов;
измеренное ускорение этим не заявляется. Контракт обновлён в EN/RU modding guide.

При нативной проверке обнаружены удерживаемые Ogg-ресурсы музыки меню. При выходе
`MusicDirector` из дерева теперь явно останавливает обе деки и освобождает Stream.
Сценарий удаления живого менеджера проверен. **Обычное завершение процесса всё ещё
сообщает об Ogg-ресурсах**, см. ограничение ниже; общий баг выхода не закрыт.

## Открытые ограничения

Отдельный native `--verify-release-only` без принудительного удаления музыкального
менеджера: 9 функциональных PASS, failures=0 и exit 0, **но 4 ObjectDB и ERROR
«2 resources still in use at exit»**. Подробный предыдущий лог назвал
OggPacketSequence/AudioStreamOggVorbis и их playback для `menu_theme_atlas.ogg`.
Это не чистая приёмка выхода; положительный код/счётчик PASS не скрывает ERROR.
Простой 30-кадровый запуск с другим треком завершился без этой ошибки, поэтому
одного такого baseline недостаточно. Причина удержания при teardown процесса
полностью не установлена. 251 ObjectDB полной кампании также не объявлены исправленными.

Единственная project-level Fennara-диагностика завершилась таймаутом plugin result;
после этого повторного запроса не делали. Независимая финальная C#-сборка успешна,
но это не успешная диагностика редактора. Fennara/autoload/MCP-конфигурация не менялись.
Полный стенд, SimBench, UI-скриншоты, экспорт и публикация GitHub не выполнялись
в этом проходе. Новых игровых строк/полей сохранения нет. Дальнейшая очередь:
отдельно закрыть обычный музыкальный teardown и продолжить измеряемые языковые
границы, сохраняя C#-владение кампанией и запрет Rust/BTA.
