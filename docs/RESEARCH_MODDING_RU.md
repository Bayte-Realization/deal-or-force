# Технологии и древо исследований

Экран открывается кнопкой «Технологии» в левой навигации или из краткой сводки исследований в окне страны. Карточка выбирает технологию для просмотра; «Начать исследование» отдаёт реальный приказ. Закрытые проекты показывают необходимые технологии, ссылки на них и следующие разработки. Переключение проекта сохраняет вложенные очки. Древо прокручивается по обеим осям; поиск работает по переведённому имени и стабильному ID.

В базовом наборе 41 технология: 17 прежних и 24 новых. Будущие ступени — условные направления, не прогноз изобретений и дат. Римские цифры в названии обозначают ступень оформления, а не отдельное вычисляемое поле. Доступность определяют `requires`, а не календарный год. Существующие ID сохранены, включая `fusion_power`, которому теперь соответствует «Энергосистемы III».

## Данные мода

Создайте JSON внутри `common/technologies/` своего включённого мода. Игра загружает базовые файлы, затем моды в порядке загрузки. Позднее определение того же ID переопределяет указанные поля, остальные наследуются. Массив `requires` и объект `effects` заменяются целиком, если присутствуют.

```json
{
  "ocean_research_2": {
    "name": "Ocean research II",
    "description": "Shared instruments and better ocean models.",
    "category": "oceanography",
    "cost": 240,
    "requires": ["research_networks"],
    "effects": { "research_speed": 0.04, "supply": 0.01 },
    "icon": "icon_research",
    "tree_column": 2,
    "tree_row": 0
  }
}
```

- `cost`: конечное число от 1, в исследовательских очках. Диффузия знаний может уменьшить фактическую стоимость.
- `category`: произвольный идентификатор; новая категория автоматически получает кнопку фильтра. Перевод задаётся ключом `research.category.oceanography`.
- `requires`: все перечисленные технологии обязательны. Циклы, неизвестные технологии и неработающие эффекты диагностируются каталогом.
- `effects`: доли бонусов (0.04 = 4%). Поддерживаются ключи действующего реестра `NationalModifiers.Keys`, в том числе `output`, `research_speed`, `army_attack`, `army_defense`, `army_speed`, `supply`. Произвольное имя не создаёт новую игровую механику. Для недельных эффектов интерфейс использует формат реестра, а не знак процента.
- `icon`: идентификатор спрайта из каталога интерфейса; при отсутствии используется исследовательская иконка.
- `tree_column`, `tree_row`: необязательные целые 0–128. Без них размещение строится по зависимостям; `null` в переопределении возвращает автоматическое размещение. При совпадении ячеек карточка сдвигается вниз. Координаты применяются и в фильтрах, и в общем дереве. Не размещайте зависимую технологию левее предшественника: граф допускает авторское расположение, но стрелки удобнее читать слева направо.

Названия и описания — ключи обычных JSON-словарей в `localization/russian/` и `localization/english/`. Непереведённая пользовательская категория отображает свой ID. Изменять ID уже выпущенной технологии нежелательно: сохранения используют именно его.

## Оформление

`game/gui/27_research_tree.json` содержит положение `layout.modal.research` и метрики:

| Токен | Назначение |
| --- | --- |
| `research.card_width`, `research.card_height` | Размер карточек |
| `research.column_gap`, `research.row_gap` | Интервалы между карточками |
| `research.card_font_size` | Кегль карточек |
| `research.details_width` | Ширина подробностей |

Значения ограничены безопасными диапазонами в рендерере, чтобы случайная правка не создавала нулевые или гигантские кнопки. Цвета берутся из общих токенов `state.positive`, `state.info`, `text.accent`, `text.muted`, `surface.line`. Положение кнопки Research в навигации задаётся `game/gui/20_campaign_structure.json`.

Эти JSON доступны существующему редактору контента: корни `common`, `gui`, `localization` уже поддерживаются; сохранение создаёт данные мода, не переписывая базовую игру. Для применения каталога перезапустите кампанию/игру с включённым модом. Это редактор данных, не визуальное перетаскивание узлов древа. Добавление нового типа эффекта или принципиально нового поведения экранов по-прежнему требует кода.

## Проверки

`TechnologyTreeTests` проверяет полный граф, детерминированное размещение, перекрёстные связи, авторские координаты, коллизии, пользовательские категории, ошибочные числа и сохранение прогресса при смене проекта. Старый research-only набор проверяет недельное исследование, диффузию, бонусы и сохранение/загрузку.
