# Прибрежные анклавы рядом с Сухумом

В исходной карте два изолированных участка — провинции 18115 и 18133 —
принадлежали Грузии, хотя все их сухопутные соседи принадлежали Абхазии.
Исправление стартовой кампании находится в отдельной, модифицируемой накладке
`game/history/provinces/zz_abkhazia_coastal_pockets.csv`.

Владелец и контролёр обоих участков теперь ABK. Границы провинций и номера
не меняются; остальные грузинские территории не передаются. При подключении
карты существующее разделение регионов согласовывает регионы с владельцами.
Это игровая правка указанного пользователем сценария, не дипломатическое
утверждение о международно признанных границах.

Новая кампания получает исправление автоматически. Сохранения с собственной
картой владения сохраняют её: прежние завоевания и редакторские изменения не
перезаписываются. Независимые сценарии не наследуют базовый ownership.csv.

`dotnet run --project Tools/MapTerritoryTests/MapTerritoryTests.csproj`
проверяет реальные координаты и соседство этих провинций, владение/контроль
на старте, согласованность регионов, сохранность остальной Грузии и сейвов,
а также отсутствие наследования правки независимыми сценариями.
При перенумерации провинций тест требует повторной проверки координат.
