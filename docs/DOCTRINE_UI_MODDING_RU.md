# Читаемость доктрин без изменения C#

Базовые значения находятся в `game/interface/10_doctrine_readability.json`.
Для своего уже созданного мода добавьте файл `interface/reading.json`, указав
только изменяемые ключи. Например:

```json
{
  "metrics": {
    "doctrine.minimum_font_pixels": 16,
    "doctrine.minimum_target_pixels": 38,
    "doctrine.card_width_pixels": 420
  }
}
```

Перезапустите игру с включённым модом. Все остальные параметры базового
интерфейса останутся прежними; копировать весь каталог `game/interface` не нужно.
Мод размещается в пользовательской `mods` игры. Создание manifest и включение
описаны в [быстром старте](MODDING_QUICKSTART_RU.md).

| Ключ | База | Значение |
| --- | ---: | --- |
| `doctrine.minimum_font_pixels` | 14 | Нижний размер основного текста |
| `doctrine.minimum_caption_pixels` | 12 | Нижний размер подписей/цен |
| `doctrine.minimum_heading_pixels` | 20 | Нижний размер большого заголовка |
| `doctrine.minimum_target_pixels` | 32 | Минимальная высота кнопок |
| `doctrine.card_width_pixels` | 380 | Ширина статьи при масштабе дерева 100% |
| `doctrine.card_height_pixels` | 208 | Минимальная высота статьи |
| `doctrine.book_height_pixels` | 80 | Минимальная высота строки каталога |

Это физические пиксели при обычной настройке интерфейса, а не единицы холста
1920×1080. Пользовательское увеличение интерфейса повышает эти минимумы.
Для книг с большим числом модификаторов высота карточки дополнительно растёт,
чтобы поля не перекрыли друг друга. Уменьшение минимума не обязано сделать
карточку ниже её содержимого. Ручное уменьшение масштаба дерева остаётся
обзорным режимом: оно намеренно уменьшает и текст внутри дерева.

Эти параметры меняют представление. Цены, сроки обучения, эффекты, prerequisites
и выбор ИИ по-прежнему задаются в существующем `common/tactical_doctrines`.
Это не новый конструктор правил и не обещание мгновенного hot reload оформления.
