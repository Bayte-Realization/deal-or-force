# EntertAlpha 0.5.3.0 — технический проход 5 ноября 2026

## Белая карта: установленная причина и границы проверки

В присланном журнале Intel HD Graphics 530 игра не смогла запустить D3D12 и
перешла на ANGLE / OpenGL ES 3 через Direct3D 11. Компиляция материала карты
останавливалась на `textureQueryLod(sampler2D, vec2)`. Подписи и значки рисовались
отдельно, поэтому могли оставаться поверх пустой геометрии. Это конкретная
несовместимость нашего материала, а не доказательство «слишком слабой карты».

Расчёт размера текстурного следа у шва теперь использует производные UV.
Для Compatibility сохранён **полный** материал: рельеф, тайлы местности, реки,
береговая вода, её движение, сглаживание и живые стратегические слои. Вместо
26 отдельных sampler-объявлений используются 12 привязок: малые таблицы,
три полноразмерных RG8-растра идентификаторов и два тайла воды объединены в
слои массивов. Слои идентификаторов не уменьшаются и не сжимаются с потерями.
Обновления владения, контроля и тумана идут в массив напрямую, без лишних 2D-копий.
Декоративный туман также читает эти же живые массивы.

Отдельный ключ `-- --safe-map` оставляет аварийный сокращённый материал. Только
он пропускает загрузку неиспользуемых картинок оформления; это **не** новый
обязательный вид игры для всех встроенных GPU. Auto больше не назначает низкий
профиль только по имени OpenGL: аппаратный рендер начинает с обычного профиля,
а существующий регулятор реагирует на измеренные кадры. Явный выбор игрока
по-прежнему имеет приоритет; программные растеризаторы распознаются отдельно.

Проверка экспорта теперь может запускать реальные OpenGL, ANGLE и Forward+,
проверяет изображение поверхности и ошибки шейдеров, сохраняет PNG, отдельно
подтверждает фактический драйвер ANGLE. Таблицы читаются обратно с GPU и сверяются
побайтно; повторная загрузка существующего слоя проверяется отдельно. Headless
сам по себе больше не считается доказательством исправной графики.

Местные прогоны выполнены на **RTX 3060**, не на HD 530. На одинаковом высоком
профиле проверены кадры с погодой и без неё. Между Compatibility и Forward+
остаются различия цвета/освещения; попиксельная эквивалентность не заявляется.
Повторный тест на компьютере автора отзыва ещё нужен. Нет обещания конкретного
FPS, «работает на любом устройстве» или готовности Android-порта.

Основы API: [массивы текстур](https://docs.godotengine.org/en/latest/classes/class_texture2darray.html),
[обновление слоя](https://docs.godotengine.org/en/latest/classes/class_imagetexturelayered.html),
[различия рендереров](https://docs.godotengine.org/en/stable/tutorials/rendering/renderers.html).

## Остальные заметки пользователя

- **Cooperation:** именованные действия используют общую фабрику дипломатических
  кнопок, геометрию, стоимость и причины недоступности. Поиск находит само действие,
  а не множество одинаковых кнопок «Предложить».
- **Формируемые страны:** нельзя компенсировать отсутствие маленького участника
  большим числом провинций основателя. Каждый обязательный компонент проверяется
  отдельно по владению **и** контролю; для объединённых Китая и Италии нужен весь
  соответствующий состав. Восстановления исчезнувших стран сохраняют свой путь.
  Это территориальная проверка, не универсальный запрет кнопки до произвольной даты.
- **Флаги:** по умолчанию сохраняется авторский национальный флаг при смене режима.
  У особых формируемых государств и движений остаются собственные правила. Мод
  может явно выбрать политические варианты через `prefer_country_base: false`.
  Объединённый Китай использует отдельный вариант по основателю CHN или TWN.
- **Редакторы / моды:** общая панель создания и выбора настоящего пакета с manifest,
  каталогами и переключением назначения. Новый пакет не включается без решения
  пользователя в лаунчере. Невалидный ID, путь наружу, ссылка и перезапись существующего
  пакета отклоняются. Документация: [пакеты модов](MOD_WORKSPACES_0530_RU.md).
- **Corecode:** проверен реальный загрузчик скомпилированного шаблона, создание
  кампании, суточный hook, отключение и повторная загрузка без дублирования hook.
  Шаблон обновлён до .NET 10. Подмена уже скомпилированного C#-класса простым
  добавлением одноимённого `.cs` не поддерживается и не обещается; для этого нужны
  API/hook, данные либо пересборка ядра. YAML остаётся частью контентного пути.
- **Luau:** одиночный `mods/luau_events` не имел manifest и не был активным модом.
  Пример перемещён в `_templates/luau_engine/corecode/modules`, повторные определения
  удалены. README прямо говорит, что это справочный модуль, а не автоматически
  зарегистрированные игровые события. Исполнение Luau VM в этом проходе не проверено.
- **Документы:** в пакет идёт отдельный аккуратный `THIRD_PARTY_NOTICES.md` на основе
  присланного варианта, без внутреннего брифа оригинальных римских рисунков.
  Реальные сторонние атрибуции и исходная история происхождения не уничтожены.
  Каталоги разработки `docs` и `licenses` в пакет игрока не добавляются.
- **Версия:** 0.5.3.0 согласована в ресурсах Windows, Godot, общей версии сборок,
  README и проверках. Публикационная ветка — EntertAlpha; ReimAlpha не переписывается.

## Дополнительные найденные сбои

В журнале тестера были два отдельных UI-исключения. Холодный вход в сетевое меню
обращался к ещё не созданному single-player picker. Escape из редактора мог
сменить сцену, после чего обработчик запрашивал viewport уже снятой сцены.
Добавлены проверки экземпляра и корректный порядок обработки ввода. До готовности
мира ввод перехватывает загрузочное покрытие. Нативный регрессионный прогон также
обнаружил обращение к удалённой кнопке старого покрытия: ссылки очищаются при закрытии,
а доступность кнопки проверяется через валидность Godot-экземпляра.

- Debug и ExportRelease: 0 ошибок / 0 предупреждений. Основной общий проект также

- 365-дневный soak: 0 нарушений проверяемых инвариантов / 0 диагностических тревог.
- Проверки документов игрока: 16 PASS; общей версии: 14 PASS; EN/RU — без новых

- Реальные местные GPU-прогоны полного материала: OpenGL, ANGLE/Direct3D 11,
  Forward+/D3D12 — `EXPORT_VERIFY failures=0`, завершение 0, без shader/script errors.
- Release-проверка UI: Cooperation, создание/выбор пакета, читаемое назначение,
  перехват ввода загрузочным покрытием и Escape обратно в меню — EN/RU,
  1920×1080 и 1280×720, `EXPORT_VERIFY failures=0`, завершение 0. Итоговые PNG
  просмотрены. Это не объявление всего интерфейса идеальным: например, карта
  ещё может сохранять старую всплывающую подсказку под большим окном.
- Упаковка реального пакета и повторный headless-прогон последней DLL: загрузка,
  60 дней, история, флаги и чистое завершение — `EXPORT_VERIFY failures=0`.

Пакет собран инкрементально: сохранён валидный ресурсный контейнер успешного
экспорта 0.5.3.0, C# пересобран в ExportRelease, свободные данные и шаблоны взяты
из актуальных исходников. Повторный полный экспорт прерван по его собственному
лимиту времени; незавершённый временный `.pck` не используется и не распространяется.
После сборки контейнера менялись код и свободные данные, а не авторские сцены/арт.
Диагностический скан Fennara не вернул результат; вместо него не заявляется
фиктивный «зелёный скан» — приведены реальные результаты компилятора и runtime.

Снимки, журналы игрока, его сейвы и временные профили проверки не являются
содержимым репозитория или готового пакета. Сквозная публикационная проверка
готового пакета и снимки интерфейса записываются отдельно в локальные журналы.
