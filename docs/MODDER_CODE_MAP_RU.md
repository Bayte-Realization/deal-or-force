# Как читать и расширять код Deal or Force

Это карта настоящих входных точек, а не отдельный API поверх игры. Начинайте с
данных: большая часть баланса и содержимого не требует нового языка, DLL или
изменения движка. Кодовые моды нужны, когда имеющихся правил действительно мало.

## Путь данных и действия

Документ JSON/YAML → каталог и его проверка → событие/решение или команда →
кампания → read-only представление интерфейса.

| Где смотреть | Что здесь происходит | Что не следует смешивать |
| --- | --- | --- |
| [StructuredData](../Scripts/Simulation/StructuredData.cs) | Безопасный JSON-совместимый YAML, порядок файлов | Формат не добавляет новых игровых ключей |
| [GameDataLoader](../Scripts/Simulation/GameDataLoader.cs) | Категории базовой игры и defines | Ссылка JsonElement не должна переживать свой JsonDocument без Clone |
| [ModLoader](../Scripts/Modding/ModLoader.cs) | Выбранные пакеты, сброс каталогов, оверлеи | Это загрузка кампании, не расчёт на каждом кадре |
| [ScriptLibrary](../Scripts/Simulation/ScriptLibrary.cs) | Именованные triggers/effects/scores | Эффект раскрывается при Parse, не через поздний поиск при каждом Apply |
| [ScriptedEffects](../Scripts/Simulation/ScriptedEffects.cs) | Словарь полей, операции, условия, числовой preview | Чтение условия не даёт разрешения менять это поле |
| [ModOperations](../Scripts/Modding/ModOperations.cs) | Проверка запроса и очередь обычных команд | `true` не означает, что действие уже выполнено |
| [ModScalarAccess](../Scripts/Modding/ModScalarAccess.cs) | Прямые старые числовые setters | Это не сделка, не проверка цены и не автоматическая сетевая синхронизация |
| [ContentWorkbench](../Scripts/Simulation/ContentWorkbench.cs) | Проверка черновика, backup, запись с защитой от внешних правок | Validate не устанавливает мод в текущую партию |
| [StabilityOutlook](../Scripts/Simulation/StabilityOutlook.cs) и [UI](../Scripts/ui/CountryStabilityOutlookUI.cs) | Пример отделения формулы от её объяснения | Открытие расчёта не должно менять кампанию |
| [DefconSystem](../Scripts/Simulation/DefconSystem.cs) | Шкала боеготовности DEFCON (5..1), мобилизация, спад торговли | Не сбрасывайте дни деэскалации вручную без соблюдения периода спокойствия |
| [Deterrence](../Scripts/Simulation/Deterrence.cs) | Ядерное сдерживание, взаимная цена войны, фактор грани фола | Tiers определяются технологиями и data-файлами, а не временными флагами |
| [CrisisLadder](../Scripts/Simulation/CrisisLadder.cs) | Дипломатические кризисы, посредники и покровители, компромиссы | Посредничество не навязывает мир игроку-человеку без явного согласия |
| [AiPeaceOutcomes](../Scripts/Simulation/AiPeaceOutcomes.cs) | 5 путей завершения войн, Кубинское правило, отражение агрессии | Нельзя аннексировать национальную территорию ядерной державы |
| [TreasuryDynamics](../Scripts/Simulation/TreasuryDynamics.cs) | Инфляционная эрозия, слив излишков, кредитный цикл, шоки | Казна не накапливается до бесконечности без политических и инфляционных издержек |

База загружается перед дополнениями и модами. Порядок выбранных пакетов задаётся
загрузчиком/лаунчером; внутри категории документы читаются по имени. `90_...` —
не универсальный приоритет поверх всех остальных пакетов. Правила Merge задаёт
конкретный каталог: не все вложенные объекты автоматически сливаются одинаково.

Манифест `manifest.json`, сохранения и документы сценария остаются JSON. YAML
поддерживается в обычных категориях содержимого; расширение не меняет схему.
Подробнее: [YAML_MODDING_RU](YAML_MODDING_RU.md).

## Единицы: самая частая причина «работает, но не так»

| Значение | Единица |
| --- | --- |
| `treasury`, `gdp`, государственный долг | Миллиарды денежных единиц игры; `1` — не один доллар |
| `stability`, `war_support`, большинство долей | От 0 до 1; `0.02` — два процентных пункта при сложении |
| `population`, `manpower` | Люди; количество может быть намного больше диапазона int |
| Сроки/кулдауны с `Days` | Дни кампании, не секунды кадра |
| Tags, culture/religion ids, branch/node ids | Внутренние идентификаторы, не локализованные названия |

Смотрите границы конкретного поля: не всякое число является долей.
Например, effects ограничивают национальную `stability` диапазоном 0.10–0.98:
`stability_set: 2` даст 0.98, а не 2 и не 1.
Поля/подсказки effects перечисляет `ScriptedEffects.Vocabulary`.

## Рабочие примеры effects

Внутри `effects` события/решения можно написать:

```yaml
treasury_percent: -0.02
stability: 0.018
state.radicalism: -0.01
```

При казне 100 списывается 2, стабильность 0.5 становится 0.518, радикализм падает
на один процентный пункт во **всех собственных регионах**. Это не только выбранная
провинция и не вся занятая армией территория. Эффект стабильности меняет текущее
значение; последующая симуляция по-прежнему может тянуть его к уровню условий.

Суффиксы: без суффикса — прибавить; `_percent` — относительное изменение;
`_mult` — умножить; `_set` — присвоить. Границы поля действуют и при `_set`.
У казны есть особое правило отрицательного остатка, а нормализация долга идёт
после всего составного эффекта — не воспроизводите финансы отдельной формулой UI.

Именованный пример `common/scripted_effects/90_guide.yml`:

```yaml
guide_double:
  treasury_mult: 2
```

Это учебная арифметика, не предложение баланса. Порядок имеет значение:

```yaml
use: [guide_double]
treasury_set: 5
```

даёт 5, а `treasury_set: 5` **перед** `use` даёт 10. JSON и YAML сохраняют этот
порядок. Вложенные библиотеки раскрываются в месте `use`. Последующая замена
библиотеки не переписывает уже разобранный эффект старого события: если нужно
поменять его развёрнутый результат, переопределите и запись события/решения.

У spirits свой порядок исполнения: сначала все удаления, затем все выдачи,
потом числовые записи. Не используйте положение `add_modifier` как инструкцию
«выполнить между двумя арифметическими строками».

## Условия только читают

```yaml
min_stability: 0.45
max_war_support: 0.8
at_war: false
```

Числовые границы соединяются через AND. `tags` — список допустимых альтернатив,
не требование одновременно иметь несколько тегов. Явный локальный `at_war`
заменяет заимствованный; у нескольких заимствованных флагов сохраняется первый.
Не стройте условие на противоречащих друг другу булевых флагах.

Ошибки парсинга нужно читать, а не игнорировать. Неверная запись может быть
пропущена, пока корректная часть блока останется: наличие объекта Effect/Trigger
само по себе не доказывает, что весь черновик принят. Диагностика содержит путь
и неизвестный ключ. В мастерской общий синтаксический Validate тоже не заменяет
доменную проверку каждого каталога при загрузке.

## Чего не заводить второй раз

`Campaign.NationById` — индекс в списке `Nations`, тот же слот, что игра записывает в `Nation.Id`, когда добавляет страну. Это не строка таблицы карты (`MapIndex`) и не тег. В командах и сохранениях держите тег.

Новое состояние пишется в сохранение и вмешивается в `CampaignFingerprint` только когда значение отличается от значения по умолчанию: кампания, которая поле не трогала, должна давать прежний отпечаток. Чтение экрана отпечаток не меняет.

Земля человека не переходит без его клика. Сделка, ультиматум и мир с человеком ждут ответа. Скрипт, который сам переписывает владельца провинции, это правило обходит.

## Ядерное сдерживание и боеготовность DEFCON (Deterrence, DefconSystem)

В игре нет сценариев ядерного апокалипсиса ради зрелища — действует строгая арифметическая модель ядерного сдерживания и стратегической боеготовности:

1. **Ядерный статус (`Deterrence.TierOf`)**:
   - Задаётся в стартовых данных `game/common/deterrence/*.json`:
     ```json
     { "holders": { "RUS": 1, "USA": 1, "CHN": 1 } }
     ```
   - Либо исследуется в партии через дерево технологий `game/common/technologies/*.json`:
     ```json
     "effects": { "deterrence": 1 }
     ```
   - ИИ ядерных держав никогда не нападает друг на друга напрямую, если включён `MutualDeterrenceEnabled` (цена войны `AiMutualDeterrencePrice` = 6, что перекрывает выгоду от любой аннексии). Противостояние смещается в сферу прокси-войн, санкций и дипломатических кризисов.

2. **Шкала DEFCON (5..1)**:
   - Автоматически рассчитывается в `DefconSystem.EvaluateTarget()`:
     - **DEFCON 5 (Peacetime)**: штатный мир.
     - **DEFCON 4 (Intelligence Watch)**: дипломатический кризис ядерных держав или участие ядерной державы в региональной войне.
     - **DEFCON 3 (Rapid Alert)**: пограничные столкновения (`TensionStage.Clashes`) или война ядерной державы с великой державой.
     - **DEFCON 2 (Armed Forces Deployment)**: прямое вооружённое столкновение двух ядерных держав или участие ядерной державы в Мировой войне (`WorldWarDay >= 0`).
     - **DEFCON 1 (Maximum Readiness / Cocked Pistol)**: затяжная (&gt;= 45 дней) или ожесточённая (|WarScore| &gt;= 40) горячая война между ядерными державами.
   - **Эффекты на геймплей**:
     - *Армия*: восстановление боевого духа и организации дивизий ускоряется (`ReadinessRecoveryMultiplier`, до +25%).
     - *Казна*: круглосуточная готовность триады облагает экономику налогом (`TreasuryDynamics`, списание с ВВП `alertDrain = Gdp * (upkeep - 1) * 0.002`).
     - *Торговля*: при DEFCON 2 и 1 мировой товарооборот сжимается на 15% и 30%.
     - *Деэскалация*: требует выдерживания 21 спокойного дня (`DefconDeescalationDays`) на каждой ступени.

## Дипломатические кризисы и покровительство великих держав (CrisisLadder)

Дипломатический кризис возникает, когда напряжённость отношений достигает `TensionStage.Crisis`, но война ещё не объявлена:
- Каждую неделю (день % 7 == 3) великие державы вмешиваются в кризис:
  - **Посредник (Mediator)**: великая держава с хорошим мнением к обеим сторонам (&gt;= 15) созывает конференции, снижающие напряжённость на 4 пункта (на 8 пунктов при DEFCON &lt;= 2!).
  - **Покровитель (Patron)**: держава, симпатизирующая одной стороне (&gt;= 40) и враждующая с другой (&lt;= -20), подливает масла в огонь (+2.5 к напряжённости).
- **Принудительный компромисс**: если за 120 дней (`CrisisCompromiseDays`) кризис не перерос в войну, мировое сообщество навязывает статус-кво: обиды и напряжённость делятся пополам.

## Реалистичные мирные соглашения и завершение войн (AiPeaceOutcomes)

Чтобы утереть нос нереалистичным механикам мирных конференций Paradox (где ИИ нарезает анклавы посреди континента или войны тянутся бесконечно со счётом 100%), Deal or Force реализует 5 строгих путей:
1. **Восстановление единства государства / Гражданская война**: если взята столица или две трети территории, государство восстанавливается целиком (`Unconditional = true`).
2. **Воссоединение (Reunification)**: войны национальной ирреденты и объединения единого народа завершаются вхождением всей территории.
3. **Кубинское правило (The Cuba Rule)**: ядерные державы при заключении мира НИКОГДА не аннексируют территорию друг друга. Порог победы снижается на `brink * 10`, а условия мира ограничиваются освобождением захваченных провинций и контрибуцией. При DEFCON &lt;= 2 это правило защищает весь мир.
4. **Отражение агрессии (Repelled Aggression)**: защитник, отбивший нападение и ведущий по счёту (`score >= 35`), забирает обратно свои оккупированные земли и репарации, не отнимая коренных земель агрессора.
5. **Предел терпения (Decisive Patience)**: если война стоит с подавляющим счётом дольше 540 дней (`AiPeaceDecisivePatienceDays`), проигравший безоговорочно признаёт поражение.

## Макроэкономика: казна, кредитный цикл и шоки (TreasuryDynamics)

В Deal or Force деньги не накапливаются в казне до триллионов — действуют естественные экономические циклы:
- **Инфляционная эрозия**: казна теряет `(Inflation - ReserveYield) / 52` в неделю.
- **Слив излишков**: запасы свыше 12% ВВП (`TreasuryComfortShare`) тратятся правительством на снижение налогов и инфраструктуру при подотчётности власти или разворовываются при коррупции.
- **Кредитный цикл (Credit Cycle)**: спокойные годы раздувают мировое кредитное плечо `WorldLeverage`. При высоком плече квадратично возрастает риск финансового краха (1929, 2008). Эпицентр бьёт по крупной экономике с долгами, а цепная реакция (Contagion) передаётся через торговые пути на глубину до 3 стран-партнёров.
- **Экономические катастрофы**: случайные шоки из `game/common/economic_shocks/*.json` (землетрясения, наводнения, эпидемии) наносят ущерб регионам и требуют экстренных бюджетных трат.

## Стабильность, имперское перенапряжение и гегемония (StabilityCore)

В отличие от игр Paradox (где великие державы бесконтрольно «красят карту», а внутренняя стабильность часто держится на одной кнопке за ману), в Deal or Force стабильность моделируется снизу вверх:
- **Региональный фундамент**: стабильность каждого региона зависит от уровня жизни (`StandardOfLiving`), радикализма, доли некоренного населения (`ForeignShare`) и оккупации.
- **Столичный фактор**: стабильность столичного региона определяет 35% государственной стабильности (`CapitalShare`), отражая исторический факт уязвимости режимов перед столичными кризисами (Петроград 1917, Париж 1789).
- **Имперское перенапряжение (Imperial Overstretch)**: держава, аннексирующая регионы с чужой культурой (инородцы > 35%) или высокой идеологической дивергенцией свыше базовой ёмкости (`BaseImperialCapacity` = 4), получает растущий штраф к государственной стабильности (до -0.18).
- **Шоки гегемонов**: великие державы не имеют искусственного «штрафа по тегу», но их крах происходит от накопленных системных противоречий: долги, дефицит, усталость от бесконечных чужих войн союзников (`WarAllyShare`), падение легитимности и рост сепаратизма на периферии.

## Безопасные операции и очередь команд (ModOperations)

- **Асинхронность**: вызовы `ModOperations.Queue*` только валидируют запрос и помещают его в `Campaign.Commands`. Действие выполняется позже в такте симуляции (`Apply`).
- **Запрет преждевременного списания**: не списывайте средства вручную возле вызова `Queue*` — команда сама проверит баланс и спишет цену при исполнении.
- **Сетевой детерминизм**: для кастомных игровых действий создавайте класс с интерфейсом `ICampaignCommand`.

## Если всё-таки нужен код

Военная «организация» на экране теперь **Morale / Боевой дух**. Для совместимости
сохраняются поле `Army.Organisation`, эффект `army.organisation` и модификатор
`organisation_recovery`. Это старые идентификаторы того же показателя, не вторая
шкала. Не заменяйте их на несуществующий `army.morale` при переводе своего мода.
Международные/общественные организации — другой смысл и не переименовывались.

Доверенный .NET-мод реализует `IGlobalityMod` из
[ModContracts](../Scripts/Modding/ModContracts.cs). Историческое имя сохранено
для совместимости. `ModContext.Nation(tag)` отдаёт живой объект, не копию;
не держите его между разными кампаниями и не меняйте из фонового потока.
У GDScript-мостика [ModApi](../Scripts/Modding/ModApi.cs) есть явные snake_case
методы, которые делегируют тем же операциям.

Для игровых действий предпочитайте `ModOperations.Queue...` / `ModContext.Queue`:
принятый запрос ещё может получить отказ при исполнении, если изменились цена,
цель или кулдаун. Не списывайте деньги второй раз рядом с постановкой в очередь.
Внутри очереди `DiagnosticLogs.TraceCommand` **сам вызывает Apply**, даже когда
логирование выключено; второй Apply рядом удвоит последствия.

Старый `ModScalarAccess.SetNationNumber` работает сразу и существует для
доверенных сценарных/кодовых инструментов. Изменение национального населения
не переписывает автоматически региональные когорты. Ни прямой setter, ни DLL
не становятся безопасной песочницей или сетевым протоколом только из-за слова API.

Если добавляете сохраняемое состояние механики: модель кампании → SaveSystem →
CampaignFingerprint → команда с повторной валидацией → preview/UI → тест save/load.
Не храните состояние страны в static-каталоге. Чистые правила остаются без
Godot.Node; экран читает модель, а не заводит второй симулятор рядом.

## Как писать полезные комментарии

- Объясняйте **почему**, единицы, владельца данных, порядок и запрещённые обходы.
- Для публичного API используйте XML summary, для локальной ловушки — короткий комментарий рядом.
- При смене правила обновляйте комментарий и пример в том же изменении.
- Не добавляйте «увеличить i» возле `i++` и не превращайте файл в пересказ каждой строки.
- Большие рецепты/таблицы держите здесь, короткую ссылку — у входной точки в коде.

## Исследования и путь к открытию

Определение проекта — `common/technologies/*.json|yaml|yml`: цена в очках,
`requires` из внутренних ID и `effects` из `NationalModifiers`. Настоящее изучение
и недельный прогресс — `TechnologyCore.ResearchSystem`, выбор —
`SetResearchCommand`. Не складывайте в `effects` команды событий: это разные схемы.

[ResearchRoute](../Scripts/Simulation/ResearchRoute.cs) строит только подсказку:
уникальные неизученные предпосылки в порядке зависимостей, сегодняшние оставшиеся
цены и ближайший доступный шаг. Не хранит очередь в Nation, не начисляет очки и
не предсказывает будущую диффузию. Переключение на карточку не равно команде выбора.
Изменения каталогов и уже изученных ID должны обновлять представление.

[YAML-пример двух технологий](../mods/_templates/yaml-data/common/technologies/70_research_routes.yml)
показывает переход между категориями. Шаблон выключен, пока моддер сам не сделает
его своим пакетом. Проверка: `--research-workspace-only`; она читает настоящий
файл и проверяет вклад исследованного проекта в формулу недельных очков.
