# Отсюда начинается код моддинга

Карта файлов, единицы величин и проверяемые примеры:
[Путеводитель по коду для моддеров](../../docs/MODDER_CODE_MAP_RU.md).

Для первого мода обычно достаточно данных, без C# и пересборки игры:
[`mods/_templates/yaml-data`](../../mods/_templates/yaml-data/README.md).
Шаблон намеренно выключен и пропускается загрузчиком в папке `_templates`.

Ключевые различия при чтении API:

- `ModOperations.Queue...` ставит намерение в очередь. Исполнитель позднее проверяет условия.
- `ModScalarAccess.Set...` — немедленный низкоуровневый доступ старого доверенного API.
- `IGlobalityMod` — актуальное имя публичного .NET-интерфейса, несмотря на историческое название.
- YAML-данные не исполняют код; скомпилированные/скриптовые моды не являются такой песочницей.

Комментарии у границ загрузки и исполнения объясняют эти ограничения. При изменении
контракта обновляйте примеры и `Tools/FormableTests/ModderExamplesTests.cs` вместе с кодом.
