# Ziva — центральная область Godot 4.8

Локальный мост для редактора, не часть игровой симуляции. Использует уже созданную
нативную панель Ziva и её браузер; не создаёт второй агент, сервер или сессию аккаунта.
Нативный плагин устанавливается отдельно и не хранится в репозитории.

## Включение

1. Установите Windows x64-версию Ziva. На проверенной машине использована 3.3.0.
2. Включите `Tools/EditorCompatibility/Ziva/plugin.cfg` в Project → Project Settings → Plugins.
3. Откройте центральную вкладку **Ziva AI** рядом с Tasks.

Мост оставляет нативную настройку `ziva/ui/use_main_screen_tab` выключенной. Центральную
область обеспечивает новый `EditorDock`, а не старый асинхронный main-screen API Ziva.
Не включайте одновременно нативную центральную вкладку в настройках Ziva.

Отключение моста возвращает нативную панель в её исходный боковой док. Панель и история
не удаляются. Сам мост освобождает только собственную пустую оболочку.

## Почему нужен мост

Godot 4.8-dev7 создаёт док для старого `get_editor_main_screen().add_child()` только
в момент подключения плагина. Асинхронное создание/перемещение панели позднее оставляет
её в скрытом `LegacyMainScreenContainer`. Мост явно регистрирует `EditorDock` с
`DOCK_LAYOUT_MAIN_SCREEN` и `DOCK_SLOT_MAIN_SCREEN`, а нативный браузер сохраняет
работающий боковой режим. Название Ziva AI отделено от нативного Ziva во избежание
неоднозначного поиска доков по заголовку.

## Диагностика 13 октября 2026

Сцены сохранены перед разрешённым перезапуском. Ziva обновлён с 3.2.8 до 3.3.0 из
официального Windows x64-архива. Старые заменённые файлы и кешированный сервис сохранены
локально в `.fennara/ziva-repair-oct13/`. Настройки аккаунта и чаты не очищались.
После неудачной автоматической замены занятого `zivacode.exe` проверена и обновлена
его отдельная копия в пользовательском каталоге игры. Журнал подтвердил готовность
страницы, поля ввода и видимого WebView2; пользователь подтвердил содержимое боковой панели.

Нативный браузер Windows не обязательно попадает в снимок текстуры Godot: проверяйте
также состояние `ZIVA_DISPLAY` в журнале и реальное окно редактора.
