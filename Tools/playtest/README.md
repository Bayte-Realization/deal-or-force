# Пробы для `Tools/game-capture.ps1`

Скрипты, которые запускает игра, когда её просят дойти до экрана и сфотографировать его:

    powershell -ExecutionPolicy Bypass -File Tools\game-capture.ps1 -Script res://Tools/playtest/walk_card5.gd

Снимки падают в `tmp_playtest/captures/<штамп>/`. Контракт самого `ctx` описан в
`addons/fennara/runtime/runtime_script_context.gd`.

## Почему файлов так много (и почему номера)

**Отредактированный файл не инстанцируется повторно.** Игра держит уже загруженный скрипт, и
правка того же пути не подхватывается: `FENNARA_SCRIPT_FAILED ... could not instantiate`. Поэтому
каждый опыт — новый файл, отсюда `probe_card2`, `...3`, `walk_card` и так далее. Это не мусор и не
небрежность, а обход правила; **копируйте в новый номер, а не правьте по кругу**.

Перекрытые итерации (ранние `walk_card*`) удалены; оставшиеся ниже.

## На что смотреть

| Файл | Зачем |
| --- | --- |
| `walk_card5.gd` | Полный проход: меню → выбор страны по карте → кампания → клик по чужой стране → **замер** карточки (`GAP=` — пустота между «Full diplomacy» и действиями) |
| `colour_check.gd` | Фотография карты: цвета стран из данных видны только здесь |
| `dossier_measure.gd` | Обход левого досье: класс, имя, `y/h/need` каждого ребёнка прокрутки |
| `probe_card*.gd`, `probe_shot*.gd`, `probe_final*.gd` | Более ранняя серия того же назначения: карточка и страница «Сценарии и мастерская». Оставлены как рабочие примеры, а не как маршрут, который надо повторять |

## Грабли, стоившие времени

- **Кнопку искать по тексту, а не по позиции.** Ширина окна различается между запусками
  (1920 и 1982 — оба настоящие), поэтому `button_path_by_text("Singleplayer")`, а не координаты.
- **Страну в выборе выбирают кликом по КАРТЕ.** Надёжно: кликать в нескольких точках, пока не
  появится `BEGIN AS CHN`, и только потом жать её.
- **`ctx.capture` принимает метку, а не узел.** Снять «только карточку» нельзя; для этого есть
  замер прямоугольников, и он точнее картинки — щель 7 px против 240 px видна только в числах.
- **`if x is Control inside:` — невалидный GDScript**, проба падает при инстанцировании. Нужно
  `var c: Control = node as Control`.
- **У `Array` в GDScript нет `.Count`** — `size()`.
- **`C:\GodotEngineNet 4.8-dev\Godot_v4.8-dev7_mono_win64_console.exe`** — консольная сборка.
- Замер `global_position.y` / `size.y` / `get_combined_minimum_size().y` даёт то, чего скриншот в
  520 px показать не может. Сравнение двух снимков по гистограмме цветов ловит **океан и
  градиенты**, а не сушу: значения палитры сверять по тексту (`git show HEAD:...`), а не глазами.
